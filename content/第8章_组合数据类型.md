# 第8章 组合数据类型

一个变量可以引用一组数据。保存学生成绩时，既需要记录每个分数，也可能需要去重、排序或按姓名查找。集合、列表、元组和字典采用不同的组织方式，选择时要看数据是否需要位置、是否允许重复，以及怎样取得其中的值。

本章根据《第8章 组合数据类型1》课件整理，依次介绍集合、序列与列表，再用函数计算基本统计值，最后说明元组与字典的基础用法。学完后，应能追踪容器在修改前后的状态，说明赋值与复制的差别，并选用适合任务的数据类型。

> **学习提示** 本章会反复使用前面学过的索引、切片、循环和函数。遇到不熟悉的写法，可以回看[第4章第2节](第4章_字符串与time库.md#2-索引与切片)、[第5章第5节](第5章_程序的控制结构.md#5-for-遍历循环)和[第6章第6节](第6章_函数定义与调用.md#6-作用域名称绑定和对象修改)。课件中的字典部分讲到键值映射与创建，本章在此基础上补充查取、更新与遍历的基础操作。

## 1. 四种组合数据类型

组合数据类型把多个对象组织在一起。先看各类型解决什么问题，再学习具体操作。

| 类型 | 常见写法 | 元素的组织方式 | 常见用途 |
| --- | --- | --- | --- |
| 集合 `set` | `{2, 4, 6}` | 元素唯一，按成员关系组织 | 去重、交并差运算 |
| 列表 `list` | `[80, 90, 80]` | 按位置排列，可修改，允许重复 | 管理和处理一组数据 |
| 元组 `tuple` | `(2026, 11, 17)` | 按位置排列，元素引用固定 | 组织固定的一组结果 |
| 字典 `dict` | `{"姓名": "小林", "成绩": 90}` | 按键对应值 | 按名称查找和更新数据 |

例如，两次调查的参与者名单可以转为集合，求出同时参与的人。每天记录的温度需要保留顺序与重复值，可以使用列表。函数返回“人数、平均分”时，可以用元组组织结果。根据姓名查询成绩时，可以使用字典建立对应关系。

<details>
<summary>术语解释 容器、元素、键和值</summary>

**容器**是能够组织其他对象的对象。放在列表、元组或集合中的每个成员称为**元素**。字典以**键值对**组织数据，键用于查找，值保存对应的数据。`scores["小林"]` 中的 `"小林"` 是键，查到的分数是值。

可变性描述对象创建后能否修改。列表、集合与字典支持原地修改。元组中的各个元素引用一旦确定就不能重新指定，字符串的字符内容也不能原地修改。

</details>

## 2. 集合的创建与元素要求

### 2.1 唯一元素与空集合

集合使用大括号或 `set()` 创建。重复加入相等的元素后，集合只保留一份。

```python
members = {"小林", "小周", "小林"}
letters = set("banana")
empty = set()

print(len(members))
print(sorted(letters))
print(type(empty).__name__)
```

依次输出 `2`、`['a', 'b', 'n']` 和 `set`。这里的 `type(obj).__name__` 取得对象类型的名称字符串。`set("banana")` 逐字符读取字符串，因此得到的是字符集合。`sorted()` 将元素整理成列表，便于稳定显示，排序规则在第8节展开。

**空集合用 `set()` 创建，空字典用 `{}` 创建。**非空集合中直接写元素，字典中写键与值的对应关系。

集合不提供位置索引。判断某个元素是否存在，可以使用 `in`。遍历或打印集合时，代码中的书写顺序不能保证成为输出顺序。题目若需要稳定的展示结果，可以先对能够比较的元素排序。

### 2.2 可哈希对象

集合需要快速判断元素是否已经存在，因而要求元素是**可哈希对象**。本章常用的整数、字符串，以及内部元素都可哈希的元组，可以作为集合元素。列表、字典和普通集合本身属于可变容器，不能直接作为集合元素。

```python
records = {"Python", 123, ("Python", 123)}
print(len(records))
print(("Python", 123) in records)
```

输出为 `3` 和 `True`。字符串、整数、元组是三个不同的元素。

<details>
<summary>术语解释 哈希与可哈希</summary>

**哈希**把对象转换为一个用于查找的整数值。可哈希对象需要在其存续期间保持稳定的哈希值，并且相等对象的哈希值一致。Python 用这一约定组织集合元素与字典键。

本章判断常见类型时，可以检查对象本身及其内部元素。元组 `(1, 2)` 可哈希，元组 `([1, 2], 3)` 含有列表，无法作为集合元素或字典键。创建后不能替换元组中的元素引用，并不能保证整个元组可哈希。

</details>

## 3. 集合之间的运算

### 3.1 并、交、差与对称差

设 `a = {1, 2, 3}`，`b = {3, 4}`。下面的运算都返回一个新集合。

| 表达式 | 名称 | 结果所含元素 |
| --- | --- | --- |
| `a | b` | 并集 | 至少出现在一个集合中的元素，得到 `{1, 2, 3, 4}` |
| `a & b` | 交集 | 同时出现在两个集合中的元素，得到 `{3}` |
| `a - b` | 差集 | 在 a 中且不在 b 中的元素，得到 `{1, 2}` |
| `b - a` | 差集 | 在 b 中且不在 a 中的元素，得到 `{4}` |
| `a ^ b` | 对称差 | 只出现在其中一个集合中的元素，得到 `{1, 2, 4}` |

`^` 对应的标准名称是**对称差**。它可以写成 `(a - b) | (b - a)`，共同出现的元素被排除。课件将这一项写作“补”，学习时按上表中的成员条件理解。

```python
a = {1, 2, 3}
b = {3, 4}

print(sorted(a | b))
print(sorted(a & b))
print(sorted(a - b))
print(sorted(a ^ b))
print(sorted(a))
```

最后仍输出 `[1, 2, 3]`。前面的普通集合运算产生新结果，名称 `a` 继续引用原集合。

### 3.2 子集与真子集

`a <= b` 表示 a 的每个元素都在 b 中。`a < b` 还要求两者不相等，称为真子集关系。`>=` 与 `>` 分别表示相应的包含关系。

```python
small = {1, 2}
large = {1, 2, 3}

print(small <= large)
print(small < small)
print(small <= small)
print({9} <= large)
```

依次输出 `True`、`False`、`True`、`False`。判断子集要逐项检查成员归属，元素个数较少本身不足以保证子集关系。

### 3.3 增强集合运算

`|=`、`&=`、`-=`、`^=` 会更新左侧集合。它们的成员规则分别与并、交、差、对称差一致。

```python
chosen = {1, 2, 3}
alias = chosen
chosen &= {2, 3, 4}

print(sorted(chosen))
print(sorted(alias))
```

两行都输出 `[2, 3]`。两个名称引用同一可变集合，通过 `&=` 修改这个集合后，从任一名称都能观察到变化。

## 4. 集合的修改、遍历与去重

### 4.1 基本方法

| 操作 | 作用 | 需要注意的情况 |
| --- | --- | --- |
| `s.add(x)` | 加入元素 x | 已存在时保持一份 |
| `s.discard(x)` | 删除元素 x | x 不存在时也能正常结束 |
| `s.remove(x)` | 删除元素 x | x 不存在时产生 `KeyError` |
| `s.pop()` | 删除并返回任意一个元素 | 空集合产生 `KeyError` |
| `s.clear()` | 清空集合 | 集合对象继续存在 |
| `s.copy()` | 建立集合副本 | 可以分别增删两份集合 |

`pop()` 的返回值取决于集合当前的内部状态，不能把它当作均匀随机抽样接口。需要随机选择时，应按[第5章第8节](第5章_程序的控制结构.md#8-random-模块与可复现的随机过程)所介绍的方法设计抽样。

```python
tasks = {"阅读", "练习"}
tasks.add("练习")
tasks.discard("绘图")
saved = tasks.copy()
tasks.remove("阅读")

print(len(tasks), "练习" in tasks)
print(len(saved), "阅读" in saved)
```

输出为 `1 True` 和 `2 True`。副本在删除前建立，后续从原集合删除元素时，副本仍保留自己的成员。

### 4.2 遍历时的状态变化

可以用 `for item in s` 逐个访问成员。若目标是反复取出并清空集合，可以直接检查集合是否还有元素。

```python
pending = {2, 4, 6}
total = 0
while pending:
    total += pending.pop()

print(total)
print(pending)
```

输出为 `12` 和 `set()`。取出顺序可能不同，每个数都恰好累加一次，因此总和固定。`while pending` 在集合为空时变假，避免继续从空集合取元素。

### 4.3 去重后的顺序

```python
values = [4, 2, 4, 1, 2]
unique = set(values)

print(len(unique))
print(sorted(unique))
```

输出为 `3` 和 `[1, 2, 4]`。集合实现了去重，排序又明确规定了升序展示。若任务要求保留第一次出现的先后关系，需要在遍历时记录是否已经遇到该元素。

```python
values = [4, 2, 4, 1, 2]
seen = set()
result = []

for value in values:
    if value not in seen:
        seen.add(value)
        result.append(value)

print(result)
```

输出 `[4, 2, 1]`。集合负责成员检查，列表负责保留输出顺序。

## 5. 序列的通用操作

字符串、列表和元组都属于序列，元素具有先后关系。正索引从0开始，负索引从末尾向前数。切片 `s[i:j:k]` 按步长 k 选取元素，终点 j 不包含在结果中。

```python
items = ["Python", 123, ".io", 8]

print(items[0])
print(items[-1])
print(items[1:3])
print(items[::-1])
```

四行依次输出 `Python`、`8`、`[123, '.io']` 和 `[8, '.io', 123, 'Python']`。切片仍然返回列表。

| 操作 | 含义 |
| --- | --- |
| `x in s`、`x not in s` | 判断元素是否存在 |
| `s + t` | 连接兼容的同类序列 |
| `s * n` | 重复序列中的元素引用 |
| `len(s)` | 元素个数 |
| `min(s)`、`max(s)` | 在元素可比较的前提下取最小、最大值 |
| `s.index(x)` | 第一次出现 x 的索引，找不到时产生 `ValueError` |
| `s.index(x, i, j)` | 在下标区间 `[i, j)` 内查找，返回原序列中的索引 |
| `s.count(x)` | 与 x 相等的元素个数 |

```python
numbers = [5, 2, 5, 8, 5]

print(numbers.index(5))
print(numbers.index(5, 1, 4))
print(numbers.count(5))
print(min(numbers), max(numbers))
```

输出依次为 `0`、`2`、`3` 和 `2 8`。限定查找区间后，返回的位置仍以整个列表为基准。

列表可以混合保存多种类型，比较操作则取决于元素本身是否支持。例如，整数与字符串混合的列表不能直接按通常的大小关系调用 `min()`。字符串之间按字符的 Unicode 编码顺序比较，多字符字符串按从左到右的顺序逐字符比较。

## 6. 列表的创建、赋值与复制

### 6.1 创建列表

使用 `[]` 创建列表，或用 `list()` 逐项收集可迭代对象中的元素。

```python
empty = []
letters = list("cat")
numbers = list(range(2, 7, 2))

print(empty)
print(letters)
print(numbers)
```

依次输出 `[]`、`['c', 'a', 't']` 和 `[2, 4, 6]`。列表长度可以随着增删操作变化，实际可容纳的数据量受内存等资源限制。

### 6.2 赋值使两个名称引用同一列表

```python
original = [10, 20, 30]
alias = original
alias[1] = 99

print(original)
print(alias)
```

两行均为 `[10, 99, 30]`。赋值建立名称绑定，原有列表对象由两个名称共同引用。通过任一名称修改其元素，另一个名称也能看到结果。

### 6.3 浅复制与嵌套对象

`original.copy()`、`original[:]` 和 `list(original)` 都能建立新的外层列表。它们把元素引用放入新列表中，这种复制称为**浅复制**。

```python
original = [[1, 2], [3, 4]]
copied = original.copy()

copied.append([5, 6])
copied[0][0] = 9

print(original)
print(copied)
```

输出为 `[[9, 2], [3, 4]]` 和 `[[9, 2], [3, 4], [5, 6]]`。向新外层列表追加元素只改变副本的长度。两个外层列表的首个元素仍引用同一个内部列表，因此修改内部列表时，两边都能观察到9。

判断复制效果时，应分别查看外层列表是否独立，以及内部可变对象是否仍被共享。

## 7. 列表的增删与切片赋值

### 7.1 增加元素

`append(x)` 把 x 整体作为一个元素追加到末尾。`insert(i, x)` 在指定位置插入一个元素。`+=` 把右侧可迭代对象中的元素逐项追加。

```python
values = [1, 2]
values.append([3, 4])
values.insert(1, 9)
values += [5, 6]

print(values)
print(len(values))
```

输出为 `[1, 9, 2, [3, 4], 5, 6]` 和 `6`。内部的 `[3, 4]` 占一个元素位置，后面的5和6分别占一个位置。

### 7.2 删除元素

| 操作 | 选择依据 | 返回结果或异常 |
| --- | --- | --- |
| `del values[i]` | 指定索引 | 删除该位置，越界时产生 `IndexError` |
| `del values[i:j]` | 指定切片 | 删除选中的位置 |
| `values.pop(i)` | 指定索引 | 删除并返回该元素 |
| `values.pop()` | 默认末尾位置 | 删除并返回最后一个元素，空列表产生 `IndexError` |
| `values.remove(x)` | 指定值 | 删除第一个匹配元素，找不到时产生 `ValueError` |
| `values.clear()` | 全部元素 | 清空列表 |

```python
values = [4, 7, 4, 9]
values.remove(4)
last = values.pop()
del values[0]

print(values)
print(last)
```

依次输出 `[4]` 和 `9`。先删除首个4得到 `[7, 4, 9]`，再取出末尾9，最后删除下标0处的7。

### 7.3 切片赋值

步长为1或省略时，切片赋值可以用不同长度的新序列替换原有区间，列表长度也会改变。

```python
values = ["cat", "dog", "tiger", 1024]
values[1:2] = [1, 2, 3, 4]
print(values)

del values[::3]
print(values)
```

第一行输出 `['cat', 1, 2, 3, 4, 'tiger', 1024]`。原来长度为1的区间被四个元素替换。删除语句按删除前的位置0、3、6选中元素，最后得到 `[1, 2, 4, 'tiger']`。

带有非1步长的切片赋值需要提供与所选位置数量相同的元素。

```python
values = [0, 1, 2, 3, 4]
values[::2] = [9, 8, 7]
print(values)
```

输出 `[9, 1, 8, 3, 7]`。选中的位置为0、2、4，因此右侧需要三个元素。若右侧只有两个元素，赋值会产生 `ValueError`。

## 8. 列表的排序、反转与嵌套

### 8.1 原地排序与生成新列表

`values.sort()` 原地修改列表，并返回 `None`。`sorted(values)` 返回一个新的有序列表。两者都可用 `reverse=True` 指定降序。

```python
values = [12, 3, 9]
ascending = sorted(values)
result = values.sort(reverse=True)

print(ascending)
print(values)
print(result)
```

输出为 `[3, 9, 12]`、`[12, 9, 3]` 和 `None`。若需要保留原有先后关系，可以把 `sorted()` 的结果绑定给另一个名称。

### 8.2 反转顺序

`values.reverse()` 在原列表中反转元素顺序，并返回 `None`。`values[::-1]` 则生成一个顺序相反的新列表。反转只改变先后顺序，原列表本身无序时，反转后的结果也未必满足大小排序。

```python
values = [3, 1, 2]
reversed_copy = values[::-1]
values.reverse()

print(values)
print(reversed_copy)
```

两行都输出 `[2, 1, 3]`。这里分别通过原地操作和切片得到相同的排列。

### 8.3 重复嵌套列表中的引用

```python
rows = [[0, 0]] * 2
rows[0][1] = 7
print(rows)
```

输出 `[[0, 7], [0, 7]]`。重复运算把同一个内部列表的引用放了两次，修改其中一行时，另一个位置观察到的是同一个对象。

若需要独立的两行，可以在循环的每次迭代中创建一个新列表。

```python
rows = []
for i in range(2):
    rows.append([0, 0])

rows[0][1] = 7
print(rows)
```

输出 `[[0, 7], [0, 0]]`。每次执行 `[0, 0]` 都创建一个新的列表。

## 9. 综合实例 基本统计值计算

### 9.1 平均值、方差与标准差

设一组数据为 $x_1, x_2, \ldots, x_n$，本节要求 $n > 0$。

平均值为

$$
\bar{x} = \frac{1}{n}\sum_{i=1}^{n}x_i
$$

本课件采用分母为 n 的总体方差。每个数减去平均值得到偏差，偏差平方后求平均。

$$
\sigma^2 = \frac{1}{n}\sum_{i=1}^{n}(x_i-\bar{x})^2
$$

标准差为方差的平方根，即 $\sigma = \sqrt{\sigma^2}$。数据为 `[2, 4, 6]` 时，平均值为4，平方偏差为4、0、4，方差为 $8/3$，标准差约为1.63。使用分母 `n - 1` 的样本方差属于另一种统计约定，调用或编写函数前需要明确采用哪一种。

### 9.2 中位数的位置

先将数据从小到大排序。长度为奇数时，中位数是下标 `n // 2` 处的值。长度为偶数时，中位数是下标 `n // 2 - 1` 与 `n // 2` 两个值的平均数。

例如，`[8, 2, 5]` 排序后为 `[2, 5, 8]`，中位数是5。`[8, 2, 5, 1]` 排序后为 `[1, 2, 5, 8]`，中位数是 `(2 + 5) / 2`，得到3.5。排序结果决定中位数的位置，原始输入中间的元素没有这一保证。

### 9.3 函数实现

下面把空数据检查、计算与输出分别写清楚。`raise ValueError(...)` 会报告输入不符合本例约定，异常的捕获方式可回看[第5章第3节](第5章_程序的控制结构.md#3-异常处理的执行路径)。

```python
def mean(numbers):
    if not numbers:
        raise ValueError("至少需要一个数")
    return sum(numbers) / len(numbers)


def variance(numbers):
    average = mean(numbers)
    squared_sum = 0.0
    for number in numbers:
        squared_sum += (number - average) ** 2
    return squared_sum / len(numbers)


def standard_deviation(numbers):
    return variance(numbers) ** 0.5


def median(numbers):
    if not numbers:
        raise ValueError("至少需要一个数")
    ordered = sorted(numbers)
    size = len(ordered)
    middle = size // 2
    if size % 2 == 1:
        return ordered[middle]
    return (ordered[middle - 1] + ordered[middle]) / 2


values = [2, 4, 6]
print(f"平均值 {mean(values):.2f}")
print(f"方差 {variance(values):.2f}")
print(f"标准差 {standard_deviation(values):.2f}")
print(f"中位数 {median(values):.2f}")
print("原数据", values)
```

输出依次为平均值 `4.00`、方差 `2.67`、标准差 `1.63`、中位数 `4.00`，以及原列表 `[2, 4, 6]`。`median()` 使用 `sorted()` 生成副本，因此求中位数后仍能保留原输入顺序。

这些函数约定元素为有限的实数。均值和方差需要除以数据个数，中位数需要存在中间元素，所以空列表应先作处理。

### 9.4 连续输入多个数

课件用空行表示输入结束。可以在循环中每次读取一行，将合法数值加入列表。

```python
def read_numbers():
    numbers = []
    while True:
        text = input("输入一个数，空行结束 ").strip()
        if text == "":
            return numbers
        try:
            number = float(text)
        except ValueError:
            print("请输入数值")
            continue
        numbers.append(number)


values = read_numbers()
if values:
    print("数据个数", len(values))
    print("平均值", sum(values) / len(values))
else:
    print("本次没有输入数据")
```

可依次输入 `2`、`4`、`6`，最后提交一个空行。代码把文本转为数值后保存，结束后输出个数3和平均值4.0。输入 `abc` 时，程序提示重新输入并继续读取。网页运行区的预设输入会演示这一过程。

## 10. 元组的创建与使用

### 10.1 逗号组织元素

元组可用 `tuple()` 创建，也可以在表达式中用逗号组织多个元素。空元组写作 `()`，单元素元组需要保留逗号。

```python
single = (5,)
number = (5)
pair = "小林", 90

print(type(single).__name__, len(single))
print(type(number).__name__)
print(pair[0], pair[-1])
```

输出为 `tuple 1`、`int` 和 `小林 90`。`(5)` 只是带分组括号的整数表达式。逗号使 `(5,)` 成为元组。

### 10.2 元素引用固定与内部对象变化

元组支持索引、切片、成员判断、计数和查找。给 `t[i]` 重新赋值会产生 `TypeError`。若其中一个元素引用可变列表，可以通过该列表自己的操作修改其内容。

```python
record = ("小林", [80, 90])
record[1].append(100)

print(record)
print(record[::-1])
```

输出为 `('小林', [80, 90, 100])` 和 `([80, 90, 100], '小林')`。元组第二个位置始终引用原列表，变化发生在列表内部。

### 10.3 多项返回与解包

```python
def bounds(numbers):
    return min(numbers), max(numbers)


low, high = bounds([7, 2, 9])
print(low, high)
```

函数返回元组 `(2, 9)`，调用处解包到两个名称，最终输出 `2 9`。这与第6章的多项返回规则相衔接。

## 11. 字典与键值映射

### 11.1 根据键查找值

字典以键值对保存数据，大括号内每组使用代码中的冒号连接键与值，也可以用 `dict()` 创建空字典。键需要可哈希，值可以使用列表等对象。

```python
capitals = {"中国": "北京", "法国": "巴黎"}
student = {"姓名": "小林", "成绩": [80, 90]}

print(capitals["中国"])
print(student["成绩"][1])
print(len(capitals))
```

依次输出 `北京`、`90` 和 `2`。`capitals["中国"]` 按键查找值，`student["成绩"][1]` 则先查到列表，再用列表索引取得第二个分数。

### 11.2 更新、添加与安全查取

对已有键赋值会更新该键对应的值，对新键赋值会增加键值对。同一个键在字典中只对应一个当前值。

```python
scores = {"小林": 80}
scores["小林"] = 92
scores["小周"] = 88

print(scores["小林"])
print(scores.get("小吴", 0))
print("小林" in scores)
print(92 in scores)
```

输出为 `92`、`0`、`True` 和 `False`。`get(key, default)` 在键缺失时返回给定默认值。省略默认值时，缺失键对应的 `get()` 结果为 `None`。使用 `scores[key]` 直接读取缺失键则产生 `KeyError`。`in` 作用于字典时检查键。

### 11.3 遍历与插入顺序

Python 3.7及以后版本保证字典保留键的插入顺序，直接遍历字典时依次取得这些键。修改已有键的值会保留该键的位置。删除后重新插入，则按重新插入的时点排列。

```python
scores = {"小林": 80, "小周": 88}
scores["小林"] = 92
scores["小吴"] = 85

for name in scores:
    print(name, scores[name])
```

依次输出 `小林 92`、`小周 88` 和 `小吴 85`。这里既使用字典的插入顺序，也通过每个键取得对应值。

课件将字典描述为“键值对之间无序”。在本章使用的现代 Python 3 环境中，可以按上述插入顺序规则理解遍历行为。字典的主要查找方式仍然是按键访问，整数键也表示相应键值对，不能直接将它当作列表的位置索引。

## 12. 本章复习要点

选用容器时，先明确要保留什么信息。集合适合成员关系与去重，列表适合按位置增删与整理数据，元组适合组织固定的元素引用，字典适合按键查找对应值。

追踪程序时，先判断操作的返回值，再判断原对象是否改变。列表的 `sort()`、`reverse()` 与 `append()` 都会修改原列表并返回 `None`。`pop()` 既修改对象，也返回被删除的元素。切片和浅复制创建新外层列表，内部可变对象仍可能共享。

计算统计值时，检查数据是否为空，明确方差的分母，并在有序数据上定位中位数。用一项数据、奇数项数据、偶数项数据和包含重复值的数据分别核对，能帮助检查不同的执行路径。

## 参考答案与解析

**第1题 B**

`set()` 建立空集合。`{}` 建立空字典，`[]` 建立空列表，`()` 建立空元组。

**第2题 D**

元组 `(1, "x")` 中的两个元素均可哈希，因此整个元组可作为集合元素。列表与字典不可哈希，含有列表的元组也不可哈希。

**第3题 A**

对称差保留只出现在其中一个集合中的元素。2和3共同出现，被排除，剩下1和4。

**第4题 C**

空集合是任意集合的子集。A中的4没有出现在右侧集合中，B中的两个集合相等，不满足真子集条件，D的左侧包含右侧没有的元素3。

**第5题 D**

`discard(9)` 在9缺失时正常结束。随后删除已有元素1，集合只剩2，长度为1，成员判断为真。

**第6题 B**

集合 `pop()` 会取出并删除一个任意成员。程序可以确定长度减少1，也可以确定返回值原先属于集合，具体成员与取出概率没有这里列出的最小值或均匀随机保证。

**第7题 C**

查找区间是下标1至3，其中第一个3位于整个列表的下标2。完整列表中共有三个3，所以输出 `2 3`。

**第8题 A**

切片 `[1:3]` 选中原来的1和2，替换为8、9、10。省略步长的连续切片允许替换长度变化，因此列表长度增加1。

**第9题 B**

切片 `[::2]` 选中0、2、4三个位置。非1步长的切片赋值要求右侧元素数量相同，两个元素不足，产生 `ValueError`。

**第10题 D**

`append([2, 3])` 把整个列表作为一个元素加入。`+= [4, 5]` 追加两个元素，最终列表为 `[1, [2, 3], 4, 5]`，长度4，下标1处为 `[2, 3]`。

**第11题 A**

`sort()` 原地升序排列，列表变为 `[2, 5, 7]`。方法返回 `None`，因此 `result` 引用空值对象。

**第12题 C**

浅复制创建了独立的外层列表，内部列表仍共享。追加9修改了两边共享的第一行，追加 `[3]` 只改变副本的外层列表。

**第13题 C**

重复运算把同一个内部列表引用放入三个位置。通过第二个位置修改内部元素后，三个位置都显示 `[5]`。

**第14题 A**

平均值为 `(1 + 3) / 2 = 2`。两个平方偏差均为1，按本章定义除以数据个数2，方差为1。

**第15题 D**

`sorted()` 创建新的有序列表并绑定给 `ordered`，原列表保留原有元素顺序。求中位数时可以在副本中定位中间元素。

**第16题 B**

排序后为 `[1, 3, 5, 9]`。长度为4，中间两个元素为3和5，平均值是4.0。

**第17题 A**

单个元素后的逗号使 `(8,)` 成为长度为1的元组，下标0处保存整数8。

**第18题 D**

元组第二个位置继续引用原来的列表，通过列表方法在其内部追加6，因此能够正常执行并显示新列表内容。

**第19题 B**

修改已有键A的值保留其位置，新键C排在已有键之后。遍历字典取得键，A的当前值为9。

**第20题 C**

字典的 `in` 检查键，`"Lin"` 在这里作为值出现，成员判断为假。键 `"age"` 缺失，`get()` 返回显式默认值0。
