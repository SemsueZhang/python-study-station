# 第6章 函数定义与调用

函数把具有明确功能的一组语句组织成可反复调用的单元。使用函数时，调用者提供输入、取得结果，具体的计算过程集中在函数内部。本章依次介绍函数定义、参数传递、返回值、作用域和匿名函数，最后用逐日累乘模型说明这些知识怎样配合使用。

学完本章，应能写出输入条件、返回值和输出行为约定清楚的函数，逐步解释一次调用的过程，判断实参与形参的对应关系，并追踪函数内外的名称绑定与对象变化。

## 1. 为什么要把代码写成函数

假设已经写好一段输出20以内素数的程序，现在还要输出100以内、365以内的素数。如果每次都复制整段程序，再修改上界，相同逻辑就会重复出现在多个位置。以后调整算法或修复错误时，需要逐处修改，容易遗漏。

可以把“输出不超过某个上界的素数”抽象成一个功能，用函数名表示这项任务，再用形参表示上界。

```python
def print_primes(limit):
    for number in range(2, limit + 1):
        for divisor in range(2, number):
            if number % divisor == 0:
                break
        else:
            print(number, end=" ")
    print()

print_primes(20)
print_primes(100)
```

这里约定形参 `limit` 接收整数，表示输出范围的上界。函数体只需写一份，调用时分别把20、100或365作为实参传入即可。

外层循环依次检查2到 `limit` 的每个整数。内层循环尝试用2到 `number - 1` 中的整数去除 `number`，只要发现能够整除的因数，就执行 `break`，结束本轮因数检查。

`else` 与内层 `for` 对齐，因此属于内层循环。内层循环没有执行 `break` 而正常结束时，说明没有找到上述范围内的因数，于是输出 `number`。当 `number` 为2时，`range(2, 2)` 为空，也属于正常结束，因此2能够正确输出。若 `limit` 小于2，外层循环为空，函数只输出最后的换行。

函数实现了代码复用，也建立了功能抽象。调用者可以通过函数名、形参和返回值约定理解用途，循环、判断等实现细节集中在定义处。

设计函数时，可以先回答三个具体问题。

- 函数完成什么任务，名称能否表达这一任务。
- 调用者需要提供什么，哪些量应设计为形参。
- 调用者需要得到什么，结果应通过返回值还是屏幕输出交付。

例如，`print_primes(limit)` 的职责是把素数输出到屏幕。如果后续还要统计个数或继续计算，可以让另一个函数返回素数列表，再由调用者决定如何处理。返回什么、是否直接输出，都会影响函数适合怎样复用。

## 2. 函数的定义和一次调用

### 2.1 定义函数的基本结构

```python
def factorial(n):
    result = 1
    for number in range(1, n + 1):
        result *= number
    return result
```

`def` 后面写函数名和括号，括号中列出形参，行末写冒号，缩进的语句组成函数体。定义中的 `n` 称为形式参数，简称形参。调用 `factorial(5)` 时提供的5称为实际参数，简称实参。

`result` 是本次计算使用的局部名称，初始值为1。循环依次把1到 `n` 乘入 `result`，最后由 `return result` 把结果交给调用者。

这个函数约定输入为非负整数。阶乘满足 `0! = 1`，当 `n` 为0时，`range(1, 1)` 为空，函数直接返回初始值1。若传入负整数，循环同样为空，也会返回1，但这已经超出约定的输入范围。需要主动拒绝这类输入时，可以在函数开头检查条件并抛出 `ValueError`。

### 2.2 定义时和调用时分别发生什么

执行 `def` 语句时，程序创建函数对象，并让函数名引用它。**后面执行调用表达式时，才会进入函数体。**

```python
def double(x):
    print("inside")
    return x * 2

print("ready")
answer = double(5)
print(answer)
```

输出顺序如下。

```text
ready
inside
10
```

执行过程可以分成五步。

1. 执行 `def`，建立名称 `double` 与函数对象的关联。
2. 执行第一个 `print`，输出 `ready`。
3. 执行调用 `double(5)`，让本次调用的形参 `x` 引用整数对象5。
4. 执行函数体，先输出 `inside`，再计算并返回10。
5. 把返回结果绑定到 `answer`，最后输出10。

**参数传递让形参名称引用实参表达式求得的对象。**函数内部通过形参访问对象。后面分析变量变化时，还需要分清某条语句是在重新绑定名称，还是在修改名称所引用的对象。

### 2.3 无形参函数也需要括号

```python
def greet():
    return "Hello"

message = greet()
```

定义时的空括号表示形参列表为空，调用时的括号表示执行函数。表达式 `greet` 取得函数对象，`greet()` 则运行函数体并取得返回结果。上例把返回的字符串 `"Hello"` 赋给 `message`。

## 3. 形参与实参怎样对应

### 3.1 位置传递和关键字传递

```python
def power(base, exponent):
    return base ** exponent

print(power(2, 3))
print(power(exponent=3, base=2))
```

两次 `power` 调用都返回8，两个 `print` 分别输出8。第一次按位置提供2和3，这两项称为位置实参，对应位置传递。第二次以 `exponent=3`、`base=2` 的形式提供值，这些项称为关键字实参，对应关键字传递。**关键字实参按形参名称匹配，因此书写顺序可以调整。**

位置传递适合实参较少、顺序容易理解的调用。关键字传递适合各项输入含义容易混淆的调用，例如 `day_up_down(up=0.012, down=0.01)`。

函数名和形参列表描述了调用接口。对于这里的普通形参，可以先按位置提供一部分实参，再按关键字提供其余实参。

```python
def combine(a, b, c):
    return a + b + c

print(combine(1, c=3, b=2))
```

这会输出6。位置实参1对应 `a`，关键字实参分别对应 `b` 和 `c`。**匹配实参时，每个普通形参只能由一个实参提供值。**`combine(1, a=2, c=3)` 通过位置和名称重复给 `a` 提供值，会引发 `TypeError`。

缺少必需实参、用不存在的形参名称提供关键字实参，也会引发 `TypeError`。普通位置实参写在关键字实参后面，例如 `combine(a=1, 2, 3)`，则会在语法检查阶段产生 `SyntaxError`。

### 3.2 带默认值的形参

```python
def factorial_div(n, divisor=1):
    result = 1
    for number in range(1, n + 1):
        result *= number
    return result // divisor

print(factorial_div(5))
print(factorial_div(5, 3))
print(factorial_div(5, divisor=3))
```

这个例子约定 `n` 接收非负整数，`divisor` 接收非零整数。`divisor` 是带默认值的形参，也称默认参数，调用时可以省略与它对应的实参。三次调用依次输出120、40、40。省略实参时使用默认值1，显式传入时使用本次提供的值。

这里的两个形参都允许按位置或关键字传入。定义这类形参时，带默认值的形参应排在不带默认值的形参后面，以便明确省略实参时的对应关系。

**默认值规定省略对应实参时采用什么，关键字传递说明调用时怎样提供实参。** 在上例中，可以通过位置传递或关键字传递为 `divisor` 提供值。

还可以把某些形参设为仅接受关键字传递。

```python
def scale(value, *, factor=1):
    return value * factor

print(scale(3, factor=2))
```

**单独的 `*` 后面的形参是仅限关键字形参，显式提供对应实参时必须写出名称。**上例中 `scale(3, factor=2)` 返回6，省略 `factor` 时则使用默认值1，因此 `scale(3)` 返回3。类似地，`def ask(prompt, *, max_tokens=100)` 中的 `max_tokens` 可以省略，也可以通过 `ask("Q", max_tokens=50)` 这样的关键字实参指定。

### 3.3 默认值在定义时求值

默认值表达式的求值时机会直接影响函数的行为。

```python
base = 10

def add_base(number, extra=base):
    return number + extra

base = 100
print(add_base(1))
```

输出11。**执行函数定义时，默认值表达式 `base` 求值得到10，函数保存这个对象作为 `extra` 的默认值。**后来把全局名称 `base` 重新绑定到100，调用 `add_base(1)` 时，省略了 `extra` 对应的实参，因此仍使用10。

如果默认值是一个可变列表，多次调用会共享这个默认列表。

```python
def collect(value, items=[]):
    items.append(value)
    return items

print(collect(1))
print(collect(2))
```

两行输出分别为 `[1]` 和 `[1, 2]`。**默认列表在执行定义时创建，后面省略 `items` 对应实参的调用会反复使用它**，因此第二次调用接着第一次的结果继续追加。需要每次独立创建列表时，可以使用 `None` 作为标记。

```python
def collect(value, items=None):
    if items is None:
        items = []
    items.append(value)
    return items
```

这样，每次省略 `items` 对应实参的调用都会先进入分支，创建一个新列表。调用者显式传入列表时，函数直接在传入的列表上追加元素。

## 4. 接收可变数量的位置实参

`*items` 会把多余的位置实参收集到一个元组中。星号是语法标记，`items` 是可以自行选择的名称，常见命名还有 `args`。

```python
def multiply_factorial(n, *factors):
    result = 1
    for number in range(1, n + 1):
        result *= number
    for factor in factors:
        result *= factor
    return result

print(multiply_factorial(3))
print(multiply_factorial(3, 2, 5))
```

第一次调用中，`n` 为3，`factors` 为空元组，返回6。第二次调用中，`factors` 为 `(2, 5)`，先算 `3!`，再依次乘2和5，返回60。

这里的“可变数量”指实参的个数可以变化，收集结果 `factors` 的类型始终是元组。它描述的是接口能够接收多少项输入，和对象内容能否原地修改属于两个概念。

调用函数时，星号还可以把现有序列展开成多个位置实参。

```python
values = (2, 5)
print(multiply_factorial(3, *values))
```

调用位置的 `*values` 把序列元素展开成位置实参，因此效果与 `multiply_factorial(3, 2, 5)` 一致。定义处的星号负责收集实参，调用处的星号负责展开序列，两种用法需要结合所在位置判断。

## 5. 返回值与屏幕输出

### 5.1 return 结束当前函数调用

```python
def absolute_value(x):
    if x < 0:
        return -x
    return x
```

当 `x` 小于0时，第一条 `return` 立即把 `-x` 返回给调用者，本次函数调用随即结束。其他输入会运行到最后一行。函数可以根据不同路径使用多条 `return`，每次调用沿实际执行的路径产生一个结果。

**在循环内部执行 `return` 会结束整个函数调用，`break` 只结束所在的那一层循环。**阅读代码时应特别注意这一范围差异。

### 5.2 未显式返回结果时返回 None

下面两种函数都会在调用完成后返回 `None`。

```python
def first():
    return


def second():
    print("done")
```

`first()` 使用空 `return`。**`second()` 执行到函数体末尾，产生隐式返回值 `None`。**因此，任意正常完成的函数调用都有一个返回对象。即使函数只负责显示内容，调用表达式的结果仍可以由调用者接收和检查。

### 5.3 多项结果通过元组组织

```python
def quotient_remainder(a, b):
    return a // b, a % b

result = quotient_remainder(17, 5)
q, r = quotient_remainder(17, 5)
print(result)
print(q, r)
```

输出如下。

```text
(3, 2)
3 2
```

这个函数要求除数 `b` 非零。**`return a // b, a % b` 把商和余数组成一个二元素元组并返回。**调用者既可以用 `result` 整体接收，也可以把两个元素解包到 `q`、`r`。使用这种普通解包方式时，左侧变量数量需要与结果元素数量匹配。

### 5.4 输出内容与返回结果

```python
def show_square(x):
    print(x * x)


def square(x):
    return x * x

result = show_square(3)
print(result)
print(square(3) + 1)
```

输出为9、`None`、10。**第一行9来自函数内部的显示操作，`show_square(3)` 本身返回 `None`。**`square(3)` 返回数值9，因此调用者能继续把它加1。

如果函数负责计算，优先让它返回计算结果。调用者再决定打印、保存还是继续计算。若函数的职责就是显示文本，内部使用 `print` 也很自然。

## 6. 作用域、名称绑定和对象修改

### 6.1 局部名称与全局名称

作用域决定程序在什么范围内查找一个名称。模块顶层定义的名称属于模块全局作用域。函数的形参，以及函数体内通常通过赋值建立的名称，属于该函数的局部作用域。

```python
n, result = 5, 100


def factorial(n):
    result = 1
    for number in range(1, n + 1):
        result *= number
    return result

print(factorial(n), result)
```

输出 `120 100`。执行 `factorial(n)` 时，先计算实参表达式 `n`，取得它引用的整数对象5，再让本次调用的形参 `n` 引用该对象。函数内部的局部名称 `result` 用于累乘，全局名称 `result` 仍引用100。

两个名称即使拼写相同，也可能分别属于局部作用域和全局作用域，形成独立的绑定。反过来，不同名称也可以引用同一个对象，例如 `a = b = []` 会让 `a`、`b` 引用同一个列表。

名称查找通常按 LEGB 顺序理解，依次是本次调用的局部作用域、外层函数作用域、模块全局作用域和内置作用域。这里的例子使用顶层函数，没有外层函数这一层。还要注意，名称如果已被判定为局部名称，却在绑定前被读取，会直接报错。后面的例子会说明这一情况。

### 6.2 global 指定模块全局名称

```python
count = 0


def add_one():
    global count
    count += 1

add_one()
add_one()
print(count)
```

输出2。`global count` 指明函数中的 `count` 使用模块全局绑定，因此后面的重新赋值会更新全局名称。

函数可以直接读取全局名称所引用的数值。**在函数内重新绑定同名全局名称时，需要先用 `global` 声明。**若把所需数据作为实参传入，再通过返回值交出新结果，调用者通常更容易看清函数的依赖。

### 6.3 读取后又赋值为什么会出错

```python
score = 10


def improve():
    print(score)
    score = 20
```

调用 `improve()` 会引发 `UnboundLocalError`。Python 3 分析函数体时，看到了对 `score` 的赋值，因此把这个名称视为本函数的局部名称。执行 `print(score)` 时，局部 `score` 还没有绑定值。

`score += 1` 同样包含对名称的赋值行为。若希望更新模块全局名称，应在函数内先写 `global score`。若希望保持函数独立，可以改成通过形参接收输入，再返回新值。

```python
def improve(score):
    return score + 1

score = improve(score)
```

**局部名称的判定覆盖整个函数体。**因此，分析这类问题时，应先找出函数内的赋值和声明，再按执行顺序追踪每个名称何时获得值。

### 6.4 修改列表对象与重新绑定名称

```python
letters = ["F", "f"]


def add_letter(value):
    letters.append(value)

add_letter("C")
print(letters)
```

输出 `['F', 'f', 'C']`。函数体读取全局名称 `letters`，找到列表，再调用 `append` 修改这个列表对象。整个过程中，全局名称仍然引用原来的列表。

如果在函数体内先给同名名称赋值，执行过程就会变化。

```python
letters = ["F", "f"]


def make_letters(value):
    letters = []
    letters.append(value)
    return letters

answer = make_letters("C")
print(letters)
print(answer)
```

依次输出 `['F', 'f']` 和 `['C']`。赋值语句在本次调用中建立局部名称 `letters`，新列表只通过这个局部名称和返回结果被访问。

分析变量变化时，应分两步判断。**先确定名称在哪个作用域绑定，再确定当前操作是在修改对象，还是让名称引用另一个对象。**对象的类型决定它支持哪些操作，名称所属的作用域则遵循统一的绑定规则。

### 6.5 形参也会引用调用者传入的对象

```python
def change(items):
    items.append(3)
    items = [99]
    return items

numbers = [1, 2]
result = change(numbers)
print(numbers)
print(result)
```

输出为 `[1, 2, 3]` 和 `[99]`。进入函数时，形参 `items` 和调用者的 `numbers` 引用同一个列表。`append(3)` 修改该共享对象，所以调用者能观察到变化。随后 `items = [99]` 让局部名称引用一个新列表，调用者的 `numbers` 继续引用原来的列表。

追踪此类程序时，可以把名称和对象分开画出。执行 `append` 时更新列表内容，执行赋值语句时更新名称所指向的对象，再检查调用者还能通过哪些名称观察到结果。

## 7. lambda 表达式

`lambda` 用于创建函数对象，形式是 `lambda 形参列表: 表达式`。调用该函数时，表达式的结果成为返回值。

```python
add = lambda x, y: x + y
print(add(10, 15))
```

输出25。赋值使名称 `add` 引用这个函数对象，也可以直接把函数对象作为实参传递。

```python
words = ["pear", "fig", "apple"]
print(sorted(words, key=lambda word: len(word)))
```

输出 `['fig', 'pear', 'apple']`。`sorted` 对每个词调用 `key` 指定的函数，取得排序依据。这里 `lambda word: len(word)` 返回字符串长度，因此三个词按3、4、5的顺序排列。

**`lambda` 的函数体是一个表达式，调用时返回该表达式的结果。**需要组织多条语句、循环或较长逻辑时，使用 `def` 更便于阅读和维护。

## 8. 综合实例 把逐日变化封装成函数

### 8.1 先约定模型与日期编号

把初始水平设为1，工作日每天乘以 `1 + up`，休息日每天乘以 `1 - down`。本例约定 `up` 为非负增长率，`down` 满足 `0 <= down < 1`，`days` 为非负整数。这是用于学习累乘和函数封装的理想化模型。

本例约定第1天为周一，`day` 从1到365，余数6和0表示周六、周日。在这个约定下，365天有261个工作日、104个休息日。

日期编号必须与星期判断配套。如果改用 `range(365)`，仍然把余数0和6设为休息日，第0天就属于休息日，计数会变成260个工作日和105个休息日。改变起始编号时，需要同步说明起始星期，再确定判断条件。

### 8.2 用形参接收可变化的规则

```python
def day_up_down(up, down=0.01, days=365):
    level = 1.0
    for day in range(1, days + 1):
        if day % 7 in (6, 0):
            level *= 1 - down
        else:
            level *= 1 + up
    return level

print("{:.3f}".format(day_up_down(0.01)))
print("{:.3f}".format(day_up_down(up=0.012, down=0.01)))
```

三个形参分别接收工作日增长率、休息日下降率和模拟天数。调用者可以只为 `up` 提供实参，也可以为 `down`、`days` 显式传入本次要使用的值。函数内的 `level` 保存逐日更新的累计值，循环结束后返回它。上面两次调用分别输出 `4.720` 和 `7.910`。

对于完整的一周，计算结果还可以写为 `(1 + up) ** 5 * (1 - down) ** 2`。循环模拟与这个公式采用同样的乘法更新规则。比较两种表达能够帮助检查工作日和休息日的计数是否一致。

### 8.3 通过调用组合完成搜索

如果希望工作日模式达到每天增长1%的365天累计水平，可以在函数外搜索增长率。

```python
target = 1.01 ** 365
candidate = 0.01

while day_up_down(candidate) < target:
    candidate += 0.001

print("{:.3f}".format(candidate))
```

外层循环负责调整候选增长率，内层函数负责在固定候选值下完成一次全年模拟。每次调用都会重新令 `level = 1.0`，因此多次尝试各自从相同初始状态开始。

候选增长率从0.01开始，每轮增加0.001。**输出的0.019表示在这组离散候选值中首次达到目标的增长率，搜索精度由步长决定。**形参接收一次模拟采用的规则，函数完成一次模拟，外层循环则负责尝试不同的实参值。

## 9. 复习提要

- 函数定义建立可调用对象，调用时运行函数体，并让形参引用实参表达式求得的对象。
- 默认值、位置传递、关键字传递分别描述不同的参数规则。
- `*args` 收集多余位置实参，收集结果为元组。
- `return` 结束当前调用。省略显式结果时返回 `None`，多项结果常组织成元组。
- 分析变量变化时，同时追踪作用域、名称引用的对象、对象是否被原地修改。
- `lambda` 创建以表达式为函数体的函数对象。
- 设计函数时，明确输入、处理、返回结果以及对外部状态的影响。

## 参考答案与解析

**第1题 B**

执行函数定义时建立函数对象，接下来先运行函数外的 `print`。调用 `hello()` 时才输出 `inside`。

**第2题 D**

括号表示调用。单独写 `greet` 会取得函数对象，`greet()` 才会运行函数体并取得结果。

**第3题 A**

`range(1, 1)` 为空，累乘变量保持初始值1。这也符合 `0! = 1`。

**第4题 C**

关键字实参按名称对应，`base=2`、`exponent=3`，结果是 `2 ** 3`，等于8。

**第5题 B**

此处 `b` 是带默认值的形参，支持位置传递和关键字传递。默认值决定省略实参时使用的值。

**第6题 D**

普通位置实参写在关键字实参后面会产生 `SyntaxError`。其他三种写法都能建立正确的参数对应关系。

**第7题 A**

默认列表在定义函数时创建。两次省略 `values` 对应实参的调用使用同一列表，追加后长度先为1、再为2。

**第8题 C**

默认值表达式在执行定义时求值，当时 `value` 为5。之后全局名称重新绑定到9，原先保存的默认值仍为5。

**第9题 D**

第一个位置实参1对应 `first`，其余位置实参2和3被 `*rest` 收集为元组 `(2, 3)`。

**第10题 A**

`rest` 为空元组，`sum(rest)` 为0，因此返回 `5 + 0`。

**第11题 B**

函数负责输出文本，运行到末尾时隐式返回 `None`。屏幕上显示的 `hello` 来自 `print`。

**第12题 C**

逗号把两个结果组织成元组，整体赋给 `answer` 后得到 `(2, 3)`。

**第13题 A**

函数内部先输出16，调用结果为 `None`，随后外部 `print(answer)` 输出 `None`。

**第14题 D**

函数只读取全局 `x`，返回11。全局绑定没有发生变化，所以第二个输出值为10。

**第15题 B**

函数中的赋值建立局部 `x`，函数返回20。模块全局 `x` 保持10。

**第16题 C**

调用时，形参 `values` 与外部名称 `items` 引用同一列表。`append(2)` 修改这个列表的内容，因此通过 `items` 输出时能够看到新增元素。

**第17题 D**

`values = [2]` 重新绑定局部形参名称。原来的列表保持 `[1]`，函数返回新列表 `[2]`。

**第18题 A**

函数体中包含对 `x` 的赋值，因此 `x` 被视为局部名称。执行第一行时该局部名称尚未绑定值。

**第19题 C**

`lambda` 表达式创建函数对象。调用 `f(3)` 时，把3绑定到 `x`，表达式 `x * 2` 计算得到6。

**第20题 B**

每天都在前一天结果的基础上更新，因此使用连乘。五个工作日对应五个 `1 + up` 因子，两个休息日对应两个 `1 - down` 因子，初始值1乘上这些因子得到一周结果。
