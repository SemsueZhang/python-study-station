# 第3章 数字类型与运算

Python 3用不同的类型表示整数、浮点数、复数和真假状态。类型决定数据支持哪些操作，运算符决定怎样计算，而精度要求决定结果应怎样比较和显示。把这几件事联系起来，就能解释一个数值表达式的结果，并为连续增长、周期变化等问题建立计算模型。

## 1. 用类型理解数据

阅读数值表达式时，可以先识别直接写出的数据，再判断每一步运算会产生什么类型的结果。例如，`3`、`3.0`和`3 + 0j`虽然可以表示相同的数值，却分别属于整数、浮点数和复数类型。

| 类型 | 常见写法 | 表达的含义 | 本章关注点 |
| --- | --- | --- | --- |
| `int` | `12`、`-7`、`0x1A` | 整数 | 精确计算与进制表示 |
| `float` | `1.5`、`2.0`、`1e3` | 浮点数 | 有限精度的近似表示 |
| `complex` | `3 + 4j` | 复数 | 实部、虚部及复数运算 |
| `bool` | `True`、`False` | 真假状态 | 与整数的关系 |
| `range` | `range(5)` | 按规律排列的整数序列 | 起点、终点和步长 |
| `NoneType` | `None` | 空值对象所属类型 | 表示缺失或尚无结果 |

内置函数`type(x)`返回对象的具体类型。内置函数`isinstance(x, T)`判断对象是否为`T`类型或其子类型的实例，因此也能反映类型之间的继承关系。这两个函数无需导入模块即可使用。

```python
print(type(3))                 # <class 'int'>
print(type(3.0))               # <class 'float'>
print(type(1e3))               # <class 'float'>
print(isinstance(True, int))   # True
```

`3 == 3.0`的结果为`True`，说明两者的数值相等。它们的类型仍分别是`int`和`float`。继续计算时，还要结合运算符判断结果类型，例如整数的真除法`3 / 1`会得到浮点数`3.0`。

## 2. 整数与进制表示

### 2.1 整数的精确性与范围

Python 3的`int`可以表示正整数、负整数和零。**整数加法、减法、乘法等运算能够保持精确值。**随着数值增大，Python 3会使用更多存储空间保存各位数字，这种机制称为任意精度整数。

实际能够处理多大的整数，还取决于可用内存、运行时间和具体实现。计算大整数时，既要判断表达式是否正确，也要考虑生成和保存结果所需的资源。

```python
print(2 ** 100)
# 1267650600228229401496703205376

print(10 ** 20 + 1)
# 100000000000000000001
```

上面两个结果都以整数形式精确保存。一般来说，结果位数越多，保存它需要的空间就越大，相关运算也可能花费更多时间。

### 2.2 四种进制写法

进制规定每一位允许使用哪些数字，以及相邻位置的位权相差多少。十进制最常见，二进制、八进制和十六进制则用特定前缀标识。同一个整数可以用不同进制书写。

| 进制 | 前缀 | 示例 | 对应十进制值 |
| --- | --- | --- | --- |
| 十进制 | 无特殊前缀 | `26` | 26 |
| 二进制 | `0b`或`0B` | `0b11010` | 26 |
| 八进制 | `0o`或`0O` | `0o32` | 26 |
| 十六进制 | `0x`或`0X` | `0x1A` | 26 |

以`0b11010`为例，从右向左的位权依次为1、2、4、8、16。把各位数字乘以相应位权再相加，得到`1 * 16 + 1 * 8 + 0 * 4 + 1 * 2 + 0 * 1`，结果为26。

十六进制需要16种数字，其中`A`至`F`分别表示10至15，字母大小写都可使用。例如，`0x1A`表示`1 * 16 + 10`，也等于26。

```python
print(26 == 0b11010 == 0o32 == 0x1A)  # True
print(bin(26))                       # 0b11010
print(oct(26))                       # 0o32
print(hex(26))                       # 0x1a
```

内置函数`bin()`、`oct()`和`hex()`把整数转换成相应进制的字符串，返回结果带有进制前缀。反过来，`int("11010", 2)`把字符串按二进制解释，得到整数26。调用时，两个实参按位置传递，其中第二个实参2指定进制。省略进制参数时，`int("11010")`会按十进制得到整数11010。

## 3. 浮点数与近似计算

### 3.1 浮点数的常见写法

浮点数字面量可以带小数点，也可以使用科学计数法。科学计数法中的`e`或`E`表示乘以10的某次幂，后面的整数给出指数。

```python
print(4.3e-3)   # 0.0043
print(9.6E5)    # 960000.0
print(1e3)      # 1000.0
```

`4.3e-3`表示`4.3 * 10 ** (-3)`。即使结果在数学上是整数，科学计数法写出的字面量仍属于`float`。

常见Python 3实现的`float`采用双精度二进制浮点表示，具有53位二进制有效精度，通常相当于约15至16位十进制有效数字。显示并还原同一个浮点数时，有时需要17位十进制数字。最大有限正数为`1.7976931348623157e308`。有效精度描述数值整体能够保留的精细程度，数值越大，能够区分的相邻数值间隔也可能越大。

某些数量级接近1的计算会出现`10 ** (-16)`附近的误差，具体的绝对误差则随数值大小和计算过程变化。因此，判断计算精度时，需要同时考虑数据规模、运算过程和允许的误差。

### 3.2 为什么`0.1 + 0.2`会出现尾数

十进制中的有限小数，在二进制中可能需要无限多位才能精确表示。例如，`0.1`的二进制小数会循环延续。**浮点数只能保存有限位，因此实际存储的是一个非常接近`0.1`的值。**后续运算使用这些已存储的近似值，还可能发生新的舍入。

```python
print(0.1 + 0.2)          # 0.30000000000000004
print(0.1 + 0.2 == 0.3)   # False
```

这两行输出可以沿着“存储、运算、显示”三步理解。Python 3先把`0.1`和`0.2`转换成有限精度的二进制浮点数，再对这两个存储值进行加法，最后把结果转换成十进制文本用于显示。得到的浮点值与`0.3`字面量对应的存储值略有差异，所以直接比较相等时得到`False`。

某些计算的显示结果很简洁，例如`0.1 + 0.3`显示为`0.4`。输出时，Python 3通常采用能够准确对应当前浮点值的简洁十进制表示。因此，显示的小数位较少，并不能作为运算完全精确的依据。

### 3.3 `round()`的规则

内置函数`round(x, d)`对数值进行舍入。`d`为正时，指定小数点后保留的位数。`d`为负时，指定舍入到十位、百位等位置。对于普通浮点数，省略`d`会得到整数结果。

```python
print(round(12.345, 2))   # 12.35
print(round(1234, -2))    # 1200
print(round(2.5))         # 2
print(round(3.5))         # 4
```

**舍入时，如果存储的数值恰好位于两个候选结果的中点，Python 3会选择末位为偶数的结果。**`2.5`位于2与3之间，选择2。`3.5`位于3与4之间，选择4，这称为向偶数舍入。

还要先判断浮点数实际保存了什么值。`round(2.675, 2)`得到`2.67`，因为字面量`2.675`保存为二进制浮点数后，与精确的十进制值存在差异，已经影响到舍入方向。

`round()`返回的是数值。**若题目要求固定显示两位小数，还需要使用字符串格式化**，例如`"{:.2f}".format(2)`会生成`"2.00"`。舍入规则与显示格式应当分别理解，字符串格式化会在第4章展开。

### 3.4 比较浮点数时使用误差范围

比较近似计算结果时，常见要求是判断两个值是否足够接近。若题目给出允许的绝对误差，可以直接计算两者差值的绝对值。也可以使用标准库模块`math`中的函数`math.isclose()`，根据相对容差和绝对容差判断。

```python
import math

value = 0.1 + 0.2
print(abs(value - 0.3) < 1e-9)   # True
print(math.isclose(value, 0.3))  # True
print(math.isclose(1e-12, 0.0, abs_tol=1e-9))  # True
```

第一种写法检查差值是否小于`1e-9`。第二种写法使用`math.isclose()`的默认容差。第三种写法通过关键字传递，为参数`abs_tol`提供实参`1e-9`，因此能够按明确的绝对容差比较接近零的两个值。

容差需要根据问题要求确定。**相对容差考虑差异相对于数值大小的比例，绝对容差直接限制差值大小。**先统一`round()`再比较，可能把原本需要区分的值舍入成相同结果，因此选择比较方法之前，应先明确精度要求。

## 4. 复数、布尔值、整数序列与空值

### 4.1 复数`complex`

复数由实部和虚部组成。数学中通常用`i`表示虚数单位，Python 3在虚数字面量后使用`j`或`J`。表达式`3 + 4j`表示实部为3、虚部为4的复数。

```python
z = 3 + 4j
print(z.real)      # 3.0
print(z.imag)      # 4.0
print(z * z)       # (-7+24j)
print(abs(z))      # 5.0
```

通过属性`.real`和`.imag`可以分别取得实部和虚部的系数，访问时不加括号。内置函数`abs(z)`返回复数的模。对于`3 + 4j`，模为`(3 ** 2 + 4 ** 2) ** 0.5`，即5.0。

复数支持加、减、乘、除等运算，可以判断相等。Python 3没有为复数提供`<`、`>`这样的大小排序，复数也不支持`//`和`%`。此外，`j`单独出现时会被当成变量名，虚数单位应写为`1j`。

### 4.2 布尔值`bool`

布尔类型只有`True`和`False`两个值，常用于保存条件判断结果，首字母必须大写。

```python
print(3 > 2)                  # True
print(True + True + False)    # 2
print(True == 1)              # True
print(type(True))             # <class 'bool'>
```

`bool`是`int`的子类型，参与这里的加法时，`True`对应1，`False`对应0，因此`True + True + False`得到2。这种性质可用于统计条件成立的次数。设计变量时，仍应明确它表示真假状态还是数量，使后续操作与实际含义一致。

### 4.3 整数序列`range`

`range()`表示按固定步长排列的不可变整数序列。它用起点、终点和步长描述取值规律，常用于控制循环次数。

| 写法 | 含义 | 序列中的元素 |
| --- | --- | --- |
| `range(4)` | 从0开始，步长为1 | 0、1、2、3 |
| `range(2, 6)` | 从2开始，步长为1 | 2、3、4、5 |
| `range(1, 8, 2)` | 从1开始，每次加2 | 1、3、5、7 |
| `range(5, 0, -2)` | 从5开始，每次减2 | 5、3、1 |

**起点可以取到，终点始终排除，负步长也遵循这个规则。**正步长不断加大数值，负步长不断减小数值。如果按指定方向无法从起点走向终点，就得到空序列。步长为0会引发`ValueError`。

```python
print(list(range(5, 0, -2)))   # [5, 3, 1]
print(list(range(1, 5, -1)))   # []
print(type(range(5)))         # <class 'range'>
```

直接显示`range(5)`时，通常看到对象的表示形式`range(0, 5)`。若想观察每个元素，可以用`list()`把序列展开为列表。`range`本身只需保存取值规则，使用时再据此取得元素，因此适合表示较大的整数范围。

### 4.4 空值`None`

**`None`是`NoneType`类型的唯一对象**，常用于表示数据缺失、某项内容尚未设置，或函数没有返回具体结果。

```python
result = None
print(type(result))      # <class 'NoneType'>
print(result is None)    # True
print(result == 0)       # False
print(result == "")      # False
```

执行`result = None`后，名称`result`引用的是空值对象。判断它是否为空值，惯用写法是`result is None`。零可以表示数量为零，空字符串可以表示一段长度为零的文本，它们与`None`分别表达不同的数据含义。

## 5. 算术运算与表达式顺序

### 5.1 常用运算符

| 运算符 | 含义 | 示例 | 结果 |
| --- | --- | --- | --- |
| `+` | 加 | `7 + 3` | `10` |
| `-` | 减 | `7 - 3` | `4` |
| `*` | 乘 | `7 * 3` | `21` |
| `/` | 真除法 | `7 / 2` | `3.5` |
| `//` | 向下取整除法 | `7 // 2` | `3` |
| `%` | 取余 | `7 % 2` | `1` |
| `**` | 幂 | `2 ** 3` | `8` |

两个整数进行真除法`/`时，结果属于浮点数。例如，`6 / 3`的商在数学上为整数，Python 3仍返回`2.0`。`//`表示向下取整除法，结果类型还取决于操作数。`7 // 2`得到整数3，`7.0 // 2`则得到浮点数`3.0`。

`/`、`//`和`%`的除数为零时会引发`ZeroDivisionError`。

### 5.2 负数的向下取整除法

**`//`的取整方向是负无穷。**商为正时，向下取整与舍弃小数部分得到相同结果。商为负时，两种处理会产生差异，需要根据方向判断。

```python
print(-7 / 3)      # -2.3333333333333335
print(-7 // 3)     # -3
print(int(-7 / 3)) # -2
print(-7 % 3)      # 2
```

`-7 / 3`约为`-2.3333`，向下取整得到小于等于它的最大整数`-3`。`int(-7 / 3)`向零截断，得到`-2`，因此这两个表达式的结果不同。

**对于整数`x`和非零整数`y`，商与余数满足`x == (x // y) * y + x % y`。**上例中的商为`-3`，要使`-7 == (-3) * 3 + 余数`成立，余数就必须为2。

**非零余数与除数同号。**例如，`7 // -3`得到`-3`，相应的余数为`-2`，两者仍满足`7 == (-3) * (-3) + (-2)`。这组关系可以用来核对负数取余题。

### 5.3 幂、单目负号与结合方向

阅读本章的算术表达式时，先处理括号中的部分，再按运算符优先级计算。幂的优先级高于乘除与取余，乘除与取余又高于加减。**同一优先级的加减乘除通常从左向右结合，幂运算则从右向左结合。**

```python
print(2 + 3 * 4)      # 14
print((2 + 3) * 4)    # 20
print(2 ** 3 ** 2)    # 512
print(-2 ** 2)        # -4
print((-2) ** 2)      # 4
print(2 ** -2)        # 0.25
```

`2 ** 3 ** 2`按`2 ** (3 ** 2)`理解。**`-2 ** 2`按`-(2 ** 2)`理解。**幂右侧允许负指数，因此`2 ** -2`仍是合法表达式。遇到容易误解的表达式，主动加括号能够明确计算意图。

### 5.4 增强赋值与混合类型运算

对于本章的数字对象，`x += y`可以按`x = x + y`理解，`-=`、`*=`、`/=`、`//=`、`%=`和`**=`同理。

```python
x = 3
x *= 4
x += 2
print(x)       # 14

x /= 2
print(x)       # 7.0
```

**对于这里的数值对象，增强赋值会把名称重新绑定到计算结果，新的结果对象可能具有不同类型。**上例中的`x`先绑定到整数14，执行`x /= 2`后又绑定到浮点数`7.0`。

普通加、减、乘等混合数值运算中，可以按`int`、`float`、`complex`的顺序理解结果类型的扩展。例如，整数与浮点数相加，`2 + 0.5`得到浮点数`2.5`。浮点数再与虚数相加，`2.5 + 1j`得到复数。

具体结果仍要结合运算符判断。两个整数做真除法会产生浮点数，整数做负整数次幂也可能产生浮点数。遇到复数时，还要确认该运算是否受支持。

## 6. 常用数值内置函数与类型转换

### 6.1 常用数值内置函数

| 内置函数 | 作用 | 示例与结果 |
| --- | --- | --- |
| `abs(x)` | 求绝对值或复数的模 | `abs(-8)`得到`8` |
| `divmod(x, y)` | 同时获得商与余数 | `divmod(10, 3)`得到`(3, 1)` |
| `pow(x, y)` | 求幂 | `pow(2, 5)`得到`32` |
| `pow(x, y, z)` | 求模幂 | `pow(2, 5, 7)`得到`4` |
| `round(x, d)` | 按指定位数舍入 | `round(3.14159, 2)`得到`3.14` |
| `max(...)` | 求最大值 | `max(3, 8, 2)`得到`8` |
| `min(...)` | 求最小值 | `min(3, 8, 2)`得到`2` |

`divmod(x, y)`同时返回向下取整除法的商和取余结果，组成一个二元组，可以用两个变量分别接收。例如，把185秒换成分钟和秒，需要先计算185除以60的商3，再保留余数5。

```python
minutes, seconds = divmod(185, 60)
print(minutes, seconds)  # 3 5
```

三参数形式`pow(x, y, z)`用于模幂计算。在底数、指数和模数均为整数，指数非负且模数非零的常见情形下，结果对应`(x ** y) % z`。计算过程中可以不断对模数取余，使中间数值保持在较小范围。例如，`pow(2, 1000, 7)`能够直接求得幂除以7的余数，省去构造完整大整数的步骤。

`max()`和`min()`可以接收多个可比较的值，也可以接收一个非空可迭代对象，例如`max([3, 8, 2])`得到8。所谓可迭代对象，是指能够依次提供元素供程序处理的对象，列表和`range`都是常见例子。求最大值和最小值时，元素之间需要具有可比较关系。

对空可迭代对象求最大值或最小值时，如果没有指定默认结果，就会触发`ValueError`。可以先判断是否为空，也可以通过关键字实参`default`指定空对象对应的结果，例如`max([], default=0)`返回0。`default`仅用于传入单个可迭代对象的形式，并且只在对象为空时生效。

### 6.2 类型转换与输入形式

`int()`、`float()`和`complex()`提供内置的数值转换功能，无需导入模块。选择转换方式时，应同时考虑输入对象的类型和希望得到的结果类型。

```python
print(int(12.9))       # 12
print(int(-12.9))      # -12
print(int("12"))       # 12
print(float("12.9"))   # 12.9
print(float(12))       # 12.0
print(complex(4))      # (4+0j)
```

`int()`的处理方式取决于传入的数据类型。**传入有限浮点数时，向零截断，因此`int(12.9)`和`int(-12.9)`分别得到12和`-12`。**传入字符串时，字符串需要符合指定进制的整数表示规则，`int("12.9")`会引发`ValueError`。

如果任务明确要求先读取小数再截断，可以写`int(float("12.9"))`。其中内层先把文本转换成浮点数12.9，外层再把它截断为整数12。每次转换都应符合输入含义和题目要求。

`float()`可以接收整数、浮点数或合法的浮点数字符串，但不能直接转换复数，即使虚部为0也会触发`TypeError`。`complex()`可以把实数转成虚部为零的复数。转换成功只表明输入可按相应规则解释，数据是否满足问题要求，还需要另外验证。

## 7. 综合实例“天天向上的力量”

### 7.1 先把语言描述变成递推关系

设初始状态为1，每天按前一天状态的固定比例增长，增长率为`r`。第一天结束时，把初始值乘以`1 + r`。第二天再次乘以同一系数，得到`1 * (1 + r) ** 2`。如此连续计算`n`天，结果为`(1 + r) ** n`。

每一天都在当前值的基础上按比例变化，因此增长效果会逐日累积。若问题给出的是每天增加固定数量，就应根据固定增量建立相应关系。先区分比例变化和数量变化，才能选对模型。

```python
rate = 0.001
up = (1 + rate) ** 365
down = (1 - rate) ** 365
print("{:.2f} {:.2f}".format(up, down))  # 1.44 0.69
```

千分之一应写成`0.001`，百分之一应写成`0.01`。把增长率绑定到一个变量名，能够保证相关计算使用同一个增长率，修改时也更方便。

| 每日变化幅度 | 连续增长365天 | 连续下降365天 |
| --- | --- | --- |
| `0.001` | 约1.44 | 约0.69 |
| `0.005` | 约6.17 | 约0.16 |
| `0.01` | 约37.78 | 约0.03 |

表中结果表示最终值与初始值的比值。1.44表示最终值约为初始值的1.44倍，对应约44%的净增长。连续下降得到0.69，则表示约剩初始值的69%。

这种逐日按比例变化的计算展示了复利效应。将模型用于现实问题时，需要明确每日变化率是否固定、变化是否始终按当前值计算，以及整个计算周期采用怎样的规则。

### 7.2 每周五天增长、两天下降

如果一周内不同日期使用不同变化率，可以逐天模拟。约定第1天为周一，每周前5天工作、后2天休息。工作日增长1%，休息日下降1%，因此两种日子的乘法系数分别为1.01和0.99。

```python
value = 1.0
rate = 0.01

for day in range(1, 366):
    if day % 7 in (6, 0):
        value *= 1 - rate
    else:
        value *= 1 + rate

print("{:.2f}".format(value))  # 4.72
```

按下面的顺序可以跟踪全年模拟。

1. `range(1, 366)`依次产生1至365，共365个整数。
2. `day % 7`在1、2、3、4、5、6、0之间周期变化。
3. 余数为6或0时，选择休息日系数`0.99`。
4. 其他情况使用工作日系数`1.01`。
5. 每次更新都以当前的`value`为基础，最终输出全年累计值。

365等于`52 * 7 + 1`。52个完整星期包含260个工作日和104个休息日，多出来的1天是周一，因此全年共有261个工作日和104个休息日。

每个工作日都乘1.01，每个休息日都乘0.99，所以最终值也可以写成`1.01 ** 261 * 0.99 ** 104`，与循环结果相互核对。这个等式依赖于每日使用固定系数的约定。若变化率还随历史状态改变，就需要重新建立更新规则。

日期编号必须与起始日约定一致。如果改用`range(365)`从0编号，却仍把余数0和6设为休息日，第一天就会被当作休息日，全年变为260个工作日和105个休息日。保持首日为周一时，可以继续使用从1开始的编号，也可以重新设计从0编号时的休息日判断。比较不同增长率之前，应先统一这些约定。

### 7.3 搜索工作日所需的增长率

现在保持休息日下降1%的规则，寻找工作日增长率，使全年结果达到每天都增长1%的水平。可以先编写一个函数，计算给定工作日增长率对应的全年结果，再从某个候选值开始逐步尝试。

```python
def yearly_value(work_rate):
    value = 1.0
    for day in range(1, 366):
        if day % 7 in (6, 0):
            value *= 0.99
        else:
            value *= 1 + work_rate
    return value


target = 1.01 ** 365
work_rate = 0.01
while yearly_value(work_rate) < target:
    work_rate += 0.001

print("{:.3f}".format(work_rate))  # 0.019
```

`yearly_value(work_rate)`接收一个工作日增长率，逐天更新状态，并用`return`把全年结果交给调用处。外面的`while`反复调用这个函数，把当前候选增长率作为实参按位置传递。结果未达到目标时，候选增长率增加`0.001`，随后重新计算全年结果。函数定义和循环语法将在后续章节展开，这里先把两个层次的计算过程分清。

目标`1.01 ** 365`直接来自每天增长1%的模型，计算过程中保留这个值，最后显示时再控制小数位。若先把目标舍入成`37.78`，用于比较的阈值就会发生轻微变化。

程序从`0.01`开始，每次增加`0.001`。输出`0.019`说明，在这组候选值中，1.9%是第一次达标的工作日增长率。**搜索步长决定能够区分多细的候选值，精确临界值还需要进一步计算。**

设临界工作日增长率为`r`，261个工作日与104个休息日对应的全年结果为`(1 + r) ** 261 * 0.99 ** 104`。令它等于目标值，得到`(1 + r) ** 261 * 0.99 ** 104 = 1.01 ** 365`。

先把等式两侧除以`0.99 ** 104`，再取261次方根，最后减去1，得到`r = (1.01 ** 365 / 0.99 ** 104) ** (1 / 261) - 1`。计算结果约为1.8081%。

**步长`0.001`对应0.1个百分点，因此程序尝试1.8%时尚未达标，下一次尝试1.9%就跨过了临界值。**缩小步长可以使搜索结果更接近临界值，同时也会增加尝试次数。

## 8. 本章复习要点

- 识别字面量时，同时检查小数点、科学计数法和进制前缀。
- `int`保持整数精确值，实际可处理规模受计算资源限制。
- `float`采用有限精度表示，误差应结合数量级和计算过程理解。
- `round()`在恰好居中时向偶数舍入，固定显示位数通过字符串格式化控制。
- `/`、`//`、`%`分别对应真除法、向下取整除法、取余。
- 负数题目可用商余恒等式核对结果，幂运算需要注意右结合和负号。
- 复数、布尔值、`range`和`None`各有自己的类型及操作规则。
- 建立模型时写清初始值、每日变化规则、周期起点和搜索步长。

## 参考答案与解析

**第1题 B**

`int`按需要增加存储空间，能够精确保存大整数。实际可计算的规模还受内存、运行时间和具体实现影响。

**第2题 A**

前缀`0x`标识十六进制，其中`A`表示10。按位权展开，`0x1A = 1 * 16 + 10 = 26`。

**第3题 C**

包含`e`或`E`的科学计数法字面量属于`float`。`2e3`的值为`2000.0`。

**第4题 D**

`0.1`和`0.2`都需要以有限精度近似保存。相加后得到`0.30000000000000004`，与字面量`0.3`对应的浮点值有差异，因此相等比较得到`False`。

**第5题 B**

`2.5`和`3.5`都能精确表示，并且恰好位于相邻整数的中点。向偶数舍入使前者选择2、后者选择4，所以二元组为`(2, 4)`。

真实商约为`-2.3333`。`//`向负无穷取整，取小于等于真实商的最大整数，因此得到`-3`。

先求向下取整除法的商，`-7 // 3`得到`-3`。再按商余关系计算，`-7 - (-3) * 3 = 2`，所以余数为2。

**第8题 D**

**第10题 C**

**第11题 A**
