# 第4章 字符串与time库

字符串用于表示和处理文本。掌握它的表示方法、索引、切片和常用方法后，就能拆分输入、组合内容，并按要求控制输出格式。时间处理也经常与文本转换结合，需要先分清时间戳、结构化时间和时间文本，再选择合适的获取、解析与计时函数。

## 1. 字符串的表示与转义

### 1.1 字符串是一段有序文本

Python 3中的`str`表示Unicode文本，可以包含汉字、英文字母、数字和各种符号。字符串中的字符有确定顺序，因此可以按位置访问、截取一段内容，也可以依次处理每个字符。

```python
name = "Python"
message = '欢迎学习'
number_text = "123"
```

引号把`"123"`标记为文本，字符串中的三个数字字符共同组成这段文本。它与整数`123`属于不同类型。字符串的`+`连接文本，所以`"12" + "3"`得到`"123"`。整数的`+`进行数值加法，`12 + 3`则得到15。

单引号与双引号都能界定字符串。若文本中包含一种引号，可以选用另一种引号作为外层界定符，减少转义。

```python
print('He said "hello".')
print("It's a good day.")
```

外层引号用于标明字符串的起止位置。例子中保留在外层引号内部的双引号和单引号，则会成为字符串内容，并随文本一起输出。

### 1.2 三引号字符串

连续三个单引号或三个双引号可以界定多行字符串。字符串内部实际输入的换行与空格都会保留下来，适合表示较长或需要分行的文本。

```python
text = """第一行
第二行"""
print(text)
```

这段代码输出两行文本。如果在第二行开头再输入四个空格，这些空格也会保存在字符串中，输出时随第二行显示。

三引号字面量可以赋给变量，也可以传给函数，具有完整的字符串含义。模块、函数或类开头的字符串还可以作为文档字符串，用来说明相应对象的用途。普通代码注释使用`#`，从该符号延续到当前行末。阅读代码时，应结合字符串出现的位置判断它的作用。

### 1.3 转义符与字符串长度

反斜线`\`与后续字符组合，可以表示换行、制表符等特殊字符，也可以让引号和反斜线本身成为字符串内容。

| 写法 | 表示的内容 | 常见用途 |
| --- | --- | --- |
| `\n` | 换行符 | 在同一字符串内分行 |
| `\t` | 制表符 | 简单文本分隔 |
| `\\` | 一个反斜线 | 表示路径等文本 |
| `\'` | 单引号 | 在单引号字符串中包含单引号 |
| `\"` | 双引号 | 在双引号字符串中包含双引号 |
| `\r` | 回车符 | 将光标移回当前行开头，效果受终端影响 |
| `\b` | 退格符 | 控制终端显示，效果受环境影响 |

```python
text = "a\nb"
print(text)
print(len(text))  # 3
```

源代码中的`\n`由反斜线和字母`n`组成，解释后成为一个换行字符。因此，`text`依次包含`a`、换行和`b`，长度为3。`print(text)`会按这个换行字符把文本分成两行输出。

在字符串前加`r`可以使用原始字符串写法，保留许多反斜线组合的原样文本。例如，`r"a\nb"`依次包含`a`、反斜线、`n`和`b`，长度为4，输出时会显示反斜线和字母`n`。

原始字符串常用于含较多反斜线的路径等文本，也需要遵守引号相关的语法限制。例如，结束引号前不能紧接奇数个连续反斜线。

## 2. 索引与切片

### 2.1 正向索引与负向索引

以字符串`"Python"`为例，长度为6，其索引对应关系如下。

| 字符 | `P` | `y` | `t` | `h` | `o` | `n` |
| --- | --- | --- | --- | --- | --- | --- |
| 正向索引 | 0 | 1 | 2 | 3 | 4 | 5 |
| 负向索引 | -6 | -5 | -4 | -3 | -2 | -1 |

正向索引从左端的0开始递增，负向索引从右端的`-1`开始向左递减。同一个字符可以由两种索引访问，例如`s[0]`与`s[-6]`都指向`P`。`s[i]`返回包含一个字符的字符串。

```python
s = "Python"
print(s[0])   # P
print(s[-1])  # n
print(s[-6])  # P
```

对于长度为6的字符串，合法索引是0至5或`-6`至`-1`。访问`s[6]`会超出范围，引发`IndexError`。如果`empty = ""`，其中没有任何字符，访问`empty[0]`或`empty[-1]`也会引发同样的异常。

### 2.2 起止位置与切片范围

`s[start:stop]`截取一段连续内容，从`start`位置开始，到`stop`位置之前停止。**起点包含在内，终点排除在外。**

```python
s = "Python"
print(s[1:4])   # yth
print(s[:3])    # Pyt
print(s[3:])    # hon
print(s[:-1])   # Pytho
print(s[:])     # Python
```

`s[1:4]`选取索引1、2、3，对应字符`y`、`t`、`h`，所以结果为`yth`。省略起点表示从开头开始，省略终点表示一直取到末尾。`s[:-1]`则把最后一个字符作为排除的终点，保留此前的内容。例如，`"26C"[:-1]`得到数值文本`"26"`。

**切片会根据字符串实际长度调整超出的边界**，因此`s[0:100]`得到整个字符串，`s[100:200]`得到空字符串。直接索引`s[100]`却会引发`IndexError`。判断边界行为时，应先确认方括号中写的是单个索引还是切片。

### 2.3 步长与反向切片

`s[start:stop:step]`用第三个分量指定步长。**正步长使索引从左向右增加，负步长使索引从右向左减小。**步长为0时无法确定下一次选取的位置，会引发`ValueError`。

```python
s = "Python"
print(s[1:5:2])    # yh
print(s[::2])      # Pto
print(s[5:0:-2])   # nhy
print(s[::-1])     # nohtyP
```

`[1:5:2]`从索引1开始，每次增加2，选取1、3，下一次到达排除的终点5时停止。`[5:0:-2]`从索引5开始，每次减小2，选取5、3、1。两者都排除终点，选取方向由步长的正负决定。

省略起止边界时，默认边界也随步长方向改变。

- 步长为正，省略起点表示从开头开始，省略终点表示一直取到末尾。
- 步长为负，省略起点表示从末尾开始，省略终点表示一直向左取过索引0。

因此，`s[::-1]`从末尾开始，依次取到索引0，实现整段反转。**负步长下省略终点，表示允许一直取到最左侧。**显式写出的`-1`仍指向最后一个字符，两种写法的终止位置不同。

```python
s = "Python"
print(s[::-1])      # nohtyP
print(s[:-1:-1])    # 空字符串
print(s[5:-1:-1])   # 空字符串
print(s[5:0:-1])    # nohty
```

返回空字符串的两个表达式中，起点都在索引5，显式终点`-1`也对应索引5。切片排除终点，因此一开始就没有可取的位置。`s[5:0:-1]`则选取5、4、3、2、1，排除索引0，所以只留下`nohty`。

## 3. 字符串不可变性与基本操作

### 3.1 对象内容与变量引用

**字符串对象创建后，其中的字符内容就固定下来，这称为不可变性。**处理文本时，可以根据原内容构造另一个字符串，再把变量绑定到处理结果。

```python
s = "Python"
t = s
s = "J" + s[1:]
print(s)  # Jython
print(t)  # Python
```

执行`t = s`后，两个名称都引用`"Python"`。随后，`s[1:]`取出`"ython"`，与`"J"`连接得到`"Jython"`，再把`s`绑定到这个结果。**`t`的绑定没有改变，因此仍输出`Python`。**

直接用`s[0] = "J"`改写某个字符，会引发`TypeError`。字符串方法也保留原对象的内容，通常通过返回值提供处理结果。若希望后续继续使用处理后的文本，需要接收这个返回值。

```python
word = "Python"
word.upper()
print(word)   # Python
word = word.upper()
print(word)   # PYTHON
```

第一次调用`word.upper()`时，程序产生大写结果，但没有保存它，`word`仍引用`"Python"`。第二次调用后执行赋值，`word`才引用`"PYTHON"`。

字符串还具有可哈希性，因此可以作为字典键。列表则无法直接用于字典键等需要可哈希对象的位置。理解其他类型时，需要分别检查其内容能否改变，以及是否支持哈希，不能只凭其中一个性质推断全部行为。

### 3.2 连接、重复、相等与包含

| 操作 | 示例 | 结果 |
| --- | --- | --- |
| 连接 | `"Py" + "thon"` | `"Python"` |
| 重复 | `"ab" * 3` | `"ababab"` |
| 相等判断 | `"Python" == "python"` | `False` |
| 子串判断 | `"tho" in "Python"` | `True` |

字符串相等比较和子串判断会区分字母大小写，因此`"Python"`与`"python"`不同。重复次数需要是整数，零次或负数次重复会得到空字符串。若要把数值接入文本，可以先转成字符串，例如`"分数" + str(90)`得到`"分数90"`。

字符串中的`in`检查一段连续子串是否出现。左侧可以是一个字符，也可以是多个字符。例如，`"tho" in "Python"`为`True`，而`"Pt" in "Python"`为`False`，因为后者的两个字符在原字符串中并不相邻。

### 3.3 长度、转换与Unicode

`len()`、`hex()`、`oct()`、`ord()`和`chr()`都是内置函数。内置转换`str()`可以生成对象的字符串表示。这些调用均无需导入模块。

```python
print(len("一二三456"))  # 6
print(str(1.23))         # 1.23
print(hex(425))          # 0x1a9
print(oct(425))          # 0o651
print(ord("A"))          # 65
print(chr(65))           # A
```

`len(s)`统计字符串中的Unicode码点个数。对于常见的单个汉字、英文字母和数字，可以按一个字符计数理解，所以`len("一二三456")`为6。较复杂的组合字符或表情可能由多个码点组成，屏幕上看到的一个图形有时会被计为多个位置。显示宽度也可能与`len()`不同，例如汉字通常比英文字母占用更宽的显示空间。

`ord()`接收包含一个字符的字符串，返回该字符的Unicode码点。`chr()`根据码点返回对应字符，因此`chr(ord("中"))`会得到`"中"`。

Unicode码点用于标识字符，UTF-8等编码则规定怎样把文本表示为字节。把字符串保存到文件或通过网络发送时，通常需要完成文本与字节之间的编码转换。

## 4. 常用字符串方法

`len(s)`把字符串作为实参交给内置函数。`s.upper()`则通过字符串对象访问其方法，点号前的`s`决定处理哪段文本。学习每个方法时，需要同时记住它接收什么参数、返回什么结果，以及是否改变原对象。

### 4.1 大小写、出现次数与替换

```python
print("AbCd".lower())              # abcd
print("AbCd".upper())              # ABCD
print("banana".count("an"))        # 2
print("aaaa".count("aa"))          # 2
print("a-b-a".replace("a", "X"))    # X-b-X
print("a-b-a".replace("a", "X", 1)) # X-b-a
```

`lower()`把可转换的字母转为小写，`upper()`转为大写。`count(sub)`统计子串互不重叠的出现次数。对于`"aaaa".count("aa")`，前两个`a`匹配一次，后两个`a`再匹配一次，因此结果为2。

`replace(old, new)`把匹配的旧子串替换为新子串，默认处理全部出现位置。可选参数`count`限制最多替换多少次。例子中把1作为第三个实参按位置传递，只把最左侧的`a`换成`X`。这些方法都通过返回值提供结果，原字符串内容保留。

### 4.2 `split()`拆分文本

`split()`把文本拆成多个字段，并用列表返回结果。拆分规则取决于是否明确指定分隔符。

```python
print("  A  B\tC  ".split())
# ['A', 'B', 'C']

print("A,,B,".split(","))
# ['A', '', 'B', '']
```

**省略分隔符时，连续的空白字符被合并为一处分界，两端空白被忽略。**空格、制表符和换行等都可以参与分隔，因此第一个例子得到三个字段`A`、`B`、`C`。

显式指定`","`时，文本按逗号位置拆分。**相邻两个逗号之间没有内容，会保留一个空字段。**末尾逗号之后也会保留空字段，所以第二个例子得到四个元素。

空字段有时用于表达缺失数据，读取时应根据输入约定决定保留、替换还是报错。分隔符本身需要有效，调用`split("")`会因空分隔符而引发`ValueError`。

### 4.3 `strip()`处理两端字符

`strip()`省略参数时，去掉字符串两端的空白字符。**提供`chars`时，会把其中列出的各个字符视为允许删除的字符集合，分别从左右两端连续检查，遇到不在集合中的字符就停止。**

```python
print("  Python \n".strip())          # Python
print("abbaPythonba".strip("ab"))    # Python
print("= python= ".strip(" =np"))    # ytho
```

第三个例子的可删除字符为等号、空格、`n`和`p`。从左端依次删除等号、空格和`p`，遇到`y`停止。从右端依次删除空格、等号和`n`，遇到`o`停止，最终留下`ytho`。两端一旦遇到需要保留的字符，就结束该方向的删除。

同样，`strip(".txt")`会把点号、`t`和`x`分别视为可删除字符，并从两端连续处理。若目标是删除完整的固定前缀或后缀，需要根据相应字符串整体进行判断，再用切片或前后缀处理方法完成。

### 4.4 `join()`连接多个字符串

`separator.join(items)`依次取出`items`中的字符串，在相邻元素之间放入`separator`，把它们连接成一个字符串。

```python
print(",".join(["A", "B", "C"]))  # A,B,C
print("-".join("123"))            # 1-2-3
print("".join(["Py", "thon"]))    # Python
```

第一个例子把列表中的三个字符串连接为`A,B,C`。第二个例子把字符串本身作为输入，依次取出字符`1`、`2`、`3`，连接为`1-2-3`。第三个例子的分隔符为空字符串，所以直接连接为`Python`。

分隔符只出现在相邻元素之间，开头和结尾不会额外增加。**所有待连接元素都必须是字符串，因此`",".join([1, 2])`会引发`TypeError`。**

### 4.5 `center()`与最小宽度

`center(width, fillchar)`把字符串放在指定宽度的中间，在两侧补足填充字符。省略`fillchar`时使用空格，明确提供时则需要给出单个字符。

```python
print("Python".center(10, "="))  # ==Python==
print("Python".center(4, "="))   # Python
```

`Python`长6个字符，居中到宽度10时还需要补4个字符，因此两侧各加2个等号。宽度4不足以容纳原字符串时，仍返回完整的`Python`。这里的宽度表示最小宽度，需要截断文本时，应另外使用切片或相应格式规则。

## 5. 字符串格式化

### 5.1 槽位与实参的对应关系

模板中的花括号标出需要填入内容的位置，称为槽位。调用字符串方法`format()`时，实参会按对应关系填入这些位置。省略编号时，依次使用第一个、第二个实参。**显式编号从0开始，还可以让多个槽位使用同一实参。**

```python
print("{}得了{}分".format("小林", 90))
print("{1}得了{0}分".format(90, "小林"))
print("{0}+{0}={1}".format(2, 4))
```

这三次方法调用都按位置传递实参。第一行按默认顺序填入姓名和分数。第二行先取编号1对应的姓名，再取编号0对应的分数，两行都输出`小林得了90分`。第三行的前两个槽位都使用编号0，所以输出`2+2=4`。

同一个模板中，自动顺序编号与显式数字编号需要保持一致，混用会引发错误。

### 5.2 填充、对齐、宽度与精度

在槽位编号后加上冒号，可以进一步指定显示格式，结构为`{实参编号:格式说明}`。格式说明按需要组合填充字符、对齐方式、最小宽度、分组符、精度和类型代码。

| 控制项 | 写法 | 含义 |
| --- | --- | --- |
| 填充字符 | `*`、`=`等 | 填补宽度不足的位置 |
| 对齐方式 | `<`、`>`、`^` | 左对齐、右对齐、居中 |
| 宽度 | 如`10` | 输出的最小宽度 |
| 千位分组 | `,` | 使用逗号分组数字 |
| 精度 | 如`.2` | 与类型结合决定小数位或文本截取长度 |
| 类型代码 | 如`d`、`f`、`%` | 决定显示形式 |

```python
print("{0:*>8}".format("Py"))       # ******Py
print("{0:=^10}".format("Python"))  # ==Python==
print("{0:,.2f}".format(12345.678)) # 12,345.68
print("{0:.3}".format("Python"))    # Pyt
```

前两个例子分别展示右对齐和居中，填充字符紧接在对齐符号之前。`{0:,.2f}`则组合了几项数字规则。编号`0`选择第一个实参，`,`要求千位分组，`.2`与`f`结合表示保留两位小数，`f`指定定点小数形式，因此得到`12,345.68`。

**格式化返回用于显示的字符串，传入的数值对象仍保留原值。**后续计算若需要该数值，可以继续使用原变量。

对字符串使用`.3`，可以限制最多输出3个字符，所以最后一个例子得到`Pyt`。对数字而言，精度的含义还取决于类型代码。学习固定小数位输出时，可以先掌握`.2f`等定点格式，再扩展其他规则。

### 5.3 数字的常见显示类型

| 类型代码 | 用途 | 示例 |
| --- | --- | --- |
| `b` | 整数的二进制 | `"{:b}".format(10)`得到`"1010"` |
| `c` | 整数对应的Unicode字符 | `"{:c}".format(65)`得到`"A"` |
| `d` | 十进制整数 | `"{:d}".format(10)`得到`"10"` |
| `o` | 八进制整数 | `"{:o}".format(10)`得到`"12"` |
| `x`、`X` | 十六进制整数 | 10分别显示为`a`或`A` |
| `e`、`E` | 科学计数形式 | `"{:.2e}".format(12.3)`得到`"1.23e+01"` |
| `f` | 定点小数形式 | `"{:.2f}".format(3)`得到`"3.00"` |
| `%` | 乘100并添加百分号 | `"{:.1%}".format(0.125)`得到`"12.5%"` |

表中的`b`、`o`、`x`等进制格式默认只显示数字部分。例如，`"{:x}".format(10)`得到`"a"`，`hex(10)`则得到带前缀的`"0xa"`。

百分号格式会先把输入乘100，再添加百分号。采用表中的`.1%`格式时，输入`0.125`得到`12.5%`。对浮点数使用`%`类型代码而不指定精度时，默认保留六位小数，因此`"{:%}".format(0.125)`得到`"12.500000%"`。如果输入已经使用12.5表示百分数的数值，就需要先明确数据约定，避免再次乘100。

f字符串允许把变量或表达式直接写进花括号，例如`f"{score:.2f}"`会按两位小数显示`score`。它与字符串方法`format()`共享许多格式说明规则，对齐、宽度、精度和类型代码都可以按相同思路理解。

## 6. 综合实例“输出星期”

要求输入1至7之间的整数，并输出对应的中文星期。把星期名称依次放入字符串后，需要先建立输入编号与字符位置的对应关系。输入1对应索引0，输入2对应索引1，因此访问时统一减1。

```python
weekdays = "一二三四五六日"
number = int(input("请输入1至7 "))

if 1 <= number <= 7:
    print("星期" + weekdays[number - 1])
else:
    print("请输入1至7之间的整数")
```

输入3时，`number - 1`为2，取出索引2的字符`三`，再连接`星期`，输出`星期三`。

程序先检查范围，再访问对应位置。若省略范围检查，输入0会转换为索引`-1`，取出末尾的`日`。这个访问在语法上合法，却不符合输入1至7的约定，因此需要把问题的合法范围与索引语法分别检查。

另一种表示方式是把七个完整星期名称连接成一个字符串。每项恰好占3个字符，第1项起点为0，第2项起点为3，第3项起点为6。因此，第`number`项的起点为`(number - 1) * 3`，再从起点取长度为3的切片。

```python
text = "星期一星期二星期三星期四星期五星期六星期日"
number = 3
start = (number - 1) * 3
print(text[start:start + 3])  # 星期三
```

这段代码用固定宽度计算分界，依赖每个名称长度相同。若各项长度不同，就需要单独保存各项或记录分界位置，再按相应规则取值。

## 7. 时间表示、UTC与本地时间

标准库模块`time`提供时间获取、格式化、解析和计时函数。使用这些标准库函数前，需要先导入对应模块或名称。

### 7.1 时间戳、结构化时间和显示文本

同一个时刻可以用秒数、日历字段或文字表示。先区分这三种形式，再选择相应的转换函数。

| 表示 | 常见类型 | 示例与用途 |
| --- | --- | --- |
| 时间戳 | `float` | 用秒数表示某个时刻 |
| 结构化时间 | `time.struct_time` | 分别保存年、月、日、时、分、秒等字段 |
| 时间文本 | `str` | 用于阅读、记录和展示 |

```python
import time

stamp = time.time()
utc_time = time.gmtime(stamp)
local_time = time.localtime(stamp)
readable = time.ctime(stamp)
```

`time.time()`返回当前时间戳，单位为秒，小数部分表示不足一秒的部分。Unix时间戳以UTC的1970年1月1日0时0分0秒为起点，用经过的秒数标识时刻。

把同一个时间戳转换成年、月、日、时等字段时，需要选择时区。时区决定这个时刻对应当地日历上的哪一天、几点。

**`time.gmtime(stamp)`按UTC生成结构化时间，返回`time.struct_time`对象。**`time.localtime(stamp)`按运行环境的本地时区生成相应日历字段，返回同一种结构化时间类型。`time.ctime(stamp)`则直接生成本地时间的易读字符串。

例子只获取一次`stamp`，随后三次转换处理的是同一个时刻，可以用来比较不同表示之间的关系。

例如，按北京时间解释时，日历时间通常比UTC快8小时。同一时刻可以在UTC表示为上午，在北京时间表示为下午。如果跨过午夜，日期也会不同。判断输出时，应先确认转换函数采用的时区。

### 7.2 结构化时间的字段

结构化时间对象`time.struct_time`把各个日历字段分别保存。常用属性包括年份`tm_year`、月份`tm_mon`、日期`tm_mday`、小时`tm_hour`、分钟`tm_min`和秒`tm_sec`。此外，`tm_wday`以0至6表示周一至周日，`tm_yday`表示一年中的第几天。

```python
import time

t = time.gmtime(0)
print(t.tm_year, t.tm_mon, t.tm_mday)  # 1970 1 1
print(t.tm_hour)                      # 0
print(t.tm_wday)                      # 3
```

时间戳0对应UTC的1970年1月1日0时0分0秒，因此前两行分别输出日期字段和小时字段。`tm_wday`为3，对应周四。

这里使用固定时间戳，所以结果与当前日期无关。若改成无参数调用`time.gmtime()`，函数会处理当前时刻，输出字段就会随运行时间变化。

## 8. 时间格式化与解析

### 8.1 `strftime()`把时间转换为文本

**标准库函数`time.strftime(template, t)`按模板把结构化时间格式化为字符串。**可以先用`gmtime()`或`localtime()`生成所需的日历字段，再交给`strftime()`决定输出形式。

```python
import time

t = time.gmtime(0)
text = time.strftime("%Y-%m-%d %H:%M:%S", t)
print(text)  # 1970-01-01 00:00:00
```

| 控制符 | 含义 | 常见结果 |
| --- | --- | --- |
| `%Y` | 含世纪的年份 | `2026` |
| `%m` | 两位月份 | `01`至`12` |
| `%d` | 两位日期 | `01`至`31` |
| `%H` | 24小时制小时 | `00`至`23` |
| `%I` | 12小时制小时 | `01`至`12` |
| `%M` | 分钟 | `00`至`59` |
| `%S` | 秒 | 常见为`00`至`59` |
| `%p` | 上午或下午标志 | 随区域设置变化 |
| `%A`、`%a` | 星期全称、缩写 | 随区域设置变化 |
| `%B`、`%b` | 月份全称、缩写 | 随区域设置变化 |

注意小写`%m`表示月份，大写`%M`表示分钟。模板中的普通字符原样保留，因此`%Y-%m-%d`使用短横线连接年月日，`%H:%M:%S`使用冒号连接时分秒，中间的空格也由模板直接提供。

`time.strftime()`通过模块名访问标准库函数，而`s.upper()`通过字符串对象访问方法。两种写法都包含点号，含义需要结合点号前面的对象判断。

### 8.2 `strptime()`把文本解析为结构化时间

**标准库函数`time.strptime(text, template)`按模板解析时间文本，返回包含年、月、日、时等字段的结构化时间。**调用时按位置传递，先提供待解析文本，再提供匹配模板。

```python
import time

t = time.strptime("2026-11-05 08:30:00", "%Y-%m-%d %H:%M:%S")
print(t.tm_year, t.tm_mon, t.tm_mday)  # 2026 11 5
print(t.tm_hour, t.tm_min)            # 8 30
```

例子中的文本依次给出年、月、日和时分秒，模板按相同顺序识别各字段。如果日期写成`2026/11/05`，模板也需要使用`%Y/%m/%d`匹配斜线。日期不合法或格式不匹配时，通常会引发`ValueError`。

上述文本与模板都没有时区信息，解析结果只给出了日历字段。若要进一步把它解释为某个具体时刻，程序还需要明确这些字段采用UTC、本地时区还是其他时区。

这两个标准库函数的转换方向相反，`strftime()`把结构化时间格式化为文本，`strptime()`把文本解析为结构化时间。时间模板使用`%Y`等控制符，字符串方法`format()`则使用`{:.2f}`等槽位规则，使用时应先分清采用哪一种机制。

## 9. 程序计时与暂停

### 9.1 用计时读数之差测量经过时间

标准库函数`time.perf_counter()`返回高分辨率性能计时器读数，单位为秒，适合测量一段操作实际经过的时间。**它使用实现规定的参考起点，测量时需要记录开始和结束两次读数，再求差值。**

```python
import time

start = time.perf_counter()
total = 0
for number in range(100000):
    total += number
elapsed = time.perf_counter() - start

print(total)                       # 4999950000
print("{:.6f}".format(elapsed))
```

这段代码先记录`start`，随后完成累加，最后读取新的计时值并减去`start`。`total`保存累加结果，`elapsed`保存两次性能计时器读数之差，也就是这段操作的经过时间。相同的求和任务会得到相同的`total`，耗时则可能随计算机性能、系统负载和运行环境变化。

单次读数的参考起点通常与程序启动时刻无关，因此应使用前后差值解释耗时。若操作很短，可以重复执行若干次，测量总经过时间后再除以次数。比较两种实现时，还应保持输入规模和运行条件一致。

### 9.2 `sleep()`让程序暂停

`time.sleep(seconds)`让当前线程暂停指定的秒数，参数可以是浮点数。

```python
import time

start = time.perf_counter()
time.sleep(0.1)
elapsed = time.perf_counter() - start
print(elapsed)
```

暂停结束后，线程还需要等待系统调度才能继续运行，因此实际经过时间通常略大于指定值。例子中的结果可能接近`0.1`，具体小数位会随运行环境变化。

**两次`perf_counter()`读数的差值表示实际经过时间，其中包含这段暂停。**`sleep()`用于控制执行节奏，性能计时器读数的差值用于测量某段过程耗时。

## 10. 本章复习要点

- 字符串由Unicode文本组成，单引号、双引号和三引号都创建字符串。
- 索引从0开始，`-1`表示最后一个字符，直接越界访问会报错。
- 切片排除终点，负步长时省略边界与显式写出`-1`存在重要区别。
- 字符串内容不可变，变量可以重新绑定到新的字符串结果。
- `split()`返回列表，`join()`连接字符串元素，`strip()`按两端字符集合处理。
- 字符串方法`format()`先确定槽位与实参的对应关系，再按对齐、宽度、精度和类型规则格式化。
- 时间戳、结构化时间和文本是不同表示，UTC与本地时间需要明确区分。
- 标准库函数`strftime()`负责时间格式化，`strptime()`负责时间解析，特别注意`%m`与`%M`。
- 程序经过时间使用`perf_counter()`读数之差，暂停时间受系统调度影响。
