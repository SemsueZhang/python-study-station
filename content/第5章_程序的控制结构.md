# 第5章 程序的控制结构

程序通过顺序、分支和循环安排执行过程。顺序决定先后，分支决定选择哪条路径，循环决定哪些操作需要重复。理解控制结构时，要把条件的计算、代码块的归属和变量的变化联系起来。

本章从条件判断讲起，再介绍分支、异常处理和循环，最后用随机数与圆周率计算串联这些知识。读例子时，可以先预测执行路径，再逐步记录变量值，检查程序如何从输入得到结果。

> **学习提示**：前4章提前出现的 `if`、`for`、`while` 和输入转换异常，会在本章完整串联。函数的 `return` 以及函数内外的变量规则还要到[第6章第5节](第6章_函数定义与调用.md#5-返回值与屏幕输出)、[第6章第6节](第6章_函数定义与调用.md#6-作用域名称绑定和对象修改)学习，涉及这些内容时先理解它对执行路径的影响。

## 1. 顺序执行与条件计算

### 1.1 三种控制结构

顺序结构使语句按先后顺序执行，分支结构根据条件选择代码块，循环结构则使代码块重复执行。这三种结构可以嵌套，例如循环内部可以通过分支决定本轮需要完成什么操作。

阅读程序时，先根据缩进划分代码块，再判断执行路径。同一代码块中的语句通常依次执行，遇到分支或循环时，再按相应规则选择下一步。空行主要用于分隔内容，代码块的归属由缩进决定。

```python
x = 3
if x > 0:
    print("正数")
print("判断结束")
```

这里`x`为3，条件`x > 0`成立，先输出`正数`，再输出`判断结束`。如果把`x`改为0或负数，分支体会被跳过，程序仍然输出`判断结束`。最后一行与`if`对齐，表示它位于分支之外。

### 1.2 比较运算和连续比较

| 运算符 | 含义 | 示例 |
| --- | --- | --- |
| `<`、`<=` | 小于、小于等于 | `score < 60` |
| `>`、`>=` | 大于、大于等于 | `score >= 90` |
| `==`、`!=` | 相等、不相等 | `guess != 99` |

**`=`用于赋值，`==`用于判断两侧的值是否相等。**对于这里使用的内置数值类型，比较运算会产生布尔结果`True`或`False`，供后续条件判断使用。

Python支持连续比较。`60 <= score < 70`表示分数大于等于60且小于70，与`60 <= score and score < 70`表达相同的区间条件。连续比较中的中间表达式只求值一次，阅读时可以把它理解为两个比较条件同时成立。

### 1.3 真值与逻辑运算

**真值**指对象用于条件判断时被视为真还是假。条件判断依据真值选择执行路径。`0`、`0.0`、空字符串、空列表和`None`的真值为假。非空字符串的真值为真，因此`"0"`和`"False"`都会使相应条件成立，字符串中文字的含义不会改变这一规则。

| 表达式 | 判断规则 | 是否继续计算右侧 |
| --- | --- | --- |
| `x and y` | 先判断`x`，`x`为假时返回`x`，否则返回`y` | `x`为真时才计算`y` |
| `x or y` | 先判断`x`，`x`为真时返回`x`，否则返回`y` | `x`为假时才计算`y` |
| `not x` | 将`x`的真值取反，返回布尔值 | 只有一个操作数 |

**`and`和`or`会根据判断过程返回其中一个操作数**，因此`0 or 5`得到整数`5`，`3 and 8`得到整数`8`。当操作数都是布尔值时，可以按通常的逻辑与、逻辑或理解。`not`始终返回布尔值。

**当左侧已经能够决定结果时，`and`和`or`会跳过右侧表达式**，这种行为称为短路求值。把前置条件写在左侧，可以让某些操作只在条件满足时执行。

```python
text = ""
if text and text[-1] == "C":
    print("摄氏温度")

denominator = 0
if denominator != 0 and 10 / denominator > 2:
    print("商大于2")
```

第一段中，空字符串的真值为假，所以程序跳过`text[-1]`，避免对空字符串取索引。第二段中，`denominator != 0`为假，所以除法被跳过。前置条件需要放在左侧，才能在求值顺序上先于被保护的操作。

这些运算的常用优先级从高到低依次为算术运算、比较运算、`not`、`and`、`or`。较长条件可以用括号明确分组。例如`(age >= 18 and has_id) or has_guardian`先把前两个条件组合，再与最后一个条件进行逻辑或运算。

## 2. 分支结构与区间覆盖

### 2.1 单分支和二分支

单分支在条件成立时执行一段操作，条件为假时跳过这段操作。二分支使用`if-else`给出两条路径，每次判断只执行其中一条。

```python
temperature = 32
if temperature > 30:
    print("天气较热")

number = 7
if number % 2 == 0:
    print("偶数")
else:
    print("奇数")
```

第一段中，32大于30，因此输出`天气较热`。第二段用`number % 2`求除以2的余数。余数为0时输出`偶数`，否则进入`else`输出`奇数`。`else`负责处理前一条件为假的情况，后面直接接冒号和代码块。

### 2.2 多分支的判断顺序

一组`if-elif-else`从上向下依次判断。**遇到第一个成立的条件后，执行对应代码块，再跳过同组中的其余分支。**如果前面的条件都为假，就执行最后的`else`。

```python
score = 85
if not 0 <= score <= 100:
    grade = "分数超出范围"
elif score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
elif score >= 60:
    grade = "D"
else:
    grade = "未及格"
print(grade)
```

这段代码输出`B`。85在合法分数范围内，因此跳过第一个分支。随后`score >= 90`为假，`score >= 80`为真，程序给`grade`赋值为`B`。由于前面的判断已经排除了90分及以上的情况，这一分支实际处理的区间是`80 <= score < 90`。

采用从高到低的等级判断时，应把较高阈值写在前面。如果先判断`score >= 60`，85会立即进入这一分支，同组中后面的80分、90分条件就没有机会继续判断。

**多个独立的`if`会分别进行判断，因此可能执行多个代码块**，适合给同一个对象添加多种标签。一组`if-elif`只选择一条路径，适合每个分数只对应一个等级。选择哪种写法，取决于这些结果是否允许同时成立。

设计多分支时，需要逐一检查各个区间是否都有处理结果。条件本身可以重叠，执行路径则由先后顺序决定。如果只在60分及以上的分支中给`grade`赋值，输入低于60分时，这个名称就可能尚未绑定值，后续输出会触发`NameError`。最后的`else`可以接住剩余情况，使每条可能执行的路径都产生所需结果。

### 2.3 条件表达式

```python
number = 7
label = "偶数" if number % 2 == 0 else "奇数"
print(label)
```

`值1 if 条件 else 值2`先判断条件，再计算被选中的表达式，整体产生一个值。上例中7除以2余1，条件为假，因此`label`得到`奇数`。这种写法适合在两个简单值之间选择。每条路径包含多项操作时，完整的`if-else`更便于表达执行过程。

## 3. 异常处理的执行路径

### 3.1 读取异常信息

异常表示某项操作在运行时无法按正常路径完成。错误信息中的异常回溯（Traceback）记录了相关调用位置，最后一行通常给出异常类型和原因。阅读时可以先确定异常类型，再沿调用位置找到自己的代码，检查对应的数据和操作。

<details>
<summary>术语解释：抛出、捕获与传播异常</summary>

**抛出异常**表示报告当前操作无法正常完成，程序可用 `raise` 主动发出异常。**捕获异常**表示用匹配的 `except` 安排处理。当前代码没有处理时，异常会向外层调用者**传播**。

例如 `raise ValueError("输入必须为正数")` 主动报告取值不符合要求，`except ValueError:` 可以处理它。**异常回溯**是错误发生时的调用位置记录，与后面递归正常返回的过程不同。

</details>

| 异常 | 典型情形 |
| --- | --- |
| `ValueError` | `int("abc")`无法转换 |
| `TypeError` | `"3" + 4`使用了不匹配的类型 |
| `NameError` | 使用尚未定义的名称 |
| `ZeroDivisionError` | 除数为0 |
| `IndexError` | 索引超出序列范围 |

读取整数字符串时，可以用`int(input())`完成转换。转换成功后，再判断数值是否满足题目范围。`eval(input())`会执行表达式求值，输入`3.5`也会得到一个能参与平方运算的浮点数，因此它无法直接承担整数字符串的格式检查。

### 3.2 try与except

```python
try:
    number = int(input("请输入整数 "))
    print(number ** 2)
except ValueError:
    print("输入需要符合整数格式")
print("本次处理结束")
```

输入`12`时，程序转换得到整数12，输出平方144，再输出`本次处理结束`。输入`abc`时，转换触发`ValueError`，`try`中后面的平方输出被跳过。程序转入匹配的`except`给出提示，处理完成后继续执行整个结构之后的语句。

**`except ValueError`只处理能够与这一类型匹配的异常。**未被处理的异常会继续向外传播，交给外层处理，或者使程序结束并报告错误。需要分别处理多类异常时，可以依次写多个`except`，并把更具体的类型放在更宽泛的类型之前。

选择捕获类型时，应围绕预期的失败原因。这里预期的是整数转换失败，因此使用`except ValueError`。裸`except`会捕获很宽的异常范围，包括某些用户中断，容易把其他问题也带入同一条处理路径。

### 3.3 else与finally

```python
try:
    divisor = int(input("请输入非零整数 "))
    result = 10 / divisor
except ValueError:
    print("整数格式错误")
except ZeroDivisionError:
    print("分母需要为非零值")
else:
    print(f"计算结果为{result:.2f}")
finally:
    print("本次尝试结束")
```

| 输入 | 执行路径 |
| --- | --- |
| `2` | `try`完成，执行`else`，再执行`finally` |
| `abc` | 转换失败，执行第一个`except`，再执行`finally` |
| `0` | 除法失败，执行第二个`except`，再执行`finally` |

`else`在`try`正常完成时执行，适合放依赖成功结果的后续操作。**`finally`适合放清理工作，在通常的Python控制流程中，即使发生异常、函数返回或循环跳转，也会在离开这一结构前执行。**它仍依赖进程能够继续运行，进程被强制终止等情形可能使清理代码来不及执行。

## 4. BMI实例的边界分析

**BMI**（Body Mass Index，身体质量指数）按`体重 / 身高**2`计算，其中体重单位为kg，身高单位为m。这个例子同时输出国际分类和国内分类，两套分类的部分阈值不同，因此需要把同一个BMI值分别映射到相应区间。

| 分类 | 国际分类对应的连续区间 | 国内分类对应的连续区间 |
| --- | --- | --- |
| 偏瘦 | 小于18.5 | 小于18.5 |
| 正常 | 大于等于18.5且小于25 | 大于等于18.5且小于24 |
| 偏胖 | 大于等于25且小于30 | 大于等于24且小于28 |
| 肥胖 | 大于等于30 | 大于等于28 |

**连续数值的区间需要首尾衔接。**如果某一档以`<= 24.9`结束，下一档从`>= 25`开始，24.91就会落在两档之间。以25为共同边界，分别使用`< 25`和`>= 25`，能够完整划分两侧数值。组合两套分类时，可以把18.5、24、25、28、30这些阈值按从小到大的顺序排列，再确定相邻阈值之间应输出什么结果。

下面的程序读取能够转换为浮点数的数字文本，并检查身高、体重是否为有限正数。`math`模块中的`isfinite()`用于排除无穷大和`NaN`等非有限值。

<details>
<summary>术语解释：溢出、下溢与非有限值</summary>

**溢出**指计算结果的大小超出当前表示可容纳的范围，浮点运算可能产生无穷大，也可能报错。**下溢**发生在非零结果太接近0时，可能损失精度，极端时舍入为0。

**`NaN`**（Not a Number，非数）是特殊浮点值，不表示一个确定的实数。它不等于自身，也不能按普通实数的大小关系分类。`math.isfinite(x)` 对无穷大和 `NaN` 返回假，用来先排除这两类值。

</details>

```python
from math import isfinite

height = float(input("身高，单位m "))
weight = float(input("体重，单位kg "))

if not (
    isfinite(height) and isfinite(weight)
    and height > 0 and weight > 0
):
    print("身高和体重需要为有限正数")
else:
    bmi = (weight / height) / height
    if not isfinite(bmi) or bmi <= 0:
        print("输入数值超出可计算范围，请检查数值和单位")
    else:
        if bmi < 18.5:
            international = domestic = "偏瘦"
        elif bmi < 24:
            international = domestic = "正常"
        elif bmi < 25:
            international, domestic = "正常", "偏胖"
        elif bmi < 28:
            international = domestic = "偏胖"
        elif bmi < 30:
            international, domestic = "偏胖", "肥胖"
        else:
            international = domestic = "肥胖"
        print(f"BMI为{bmi:.2f}")
        print(f"国际分类为{international}，国内分类为{domestic}")
```

**程序先检查输入，再检查计算结果，只有得到有限正数的BMI才进行分类。**连续除以两次身高，在数学上等价于除以身高平方，可以避开先计算平方造成的中间结果溢出或下溢。不过，极端数值仍可能使除法结果成为无穷大或下溢为0，因此还需要检查`bmi`。身高为1.75、体重为70时，BMI约为22.857，两种分类都是正常。BMI为24.91时，前面的`bmi < 24`为假，接着进入`bmi < 25`的分支，得到国际正常、国内偏胖。

**分类使用原始计算值，输出时再保留两位小数。**例如24.999会显示为25.00，但参与条件判断的值仍然小于25。数值计算、区间判断和格式化显示分别完成不同的工作，阅读程序时应分别追踪。

检查分类程序时，先代入18.5、24、25、28、30这些边界，再代入各边界左右很近的值。这样既能检查端点是否属于正确区间，也能发现区间之间的空隙。

## 5. for 遍历循环

### 5.1 循环变量如何变化

```python
total = 0
for number in range(1, 5):
    total += number
print(total)
```

`range(1, 5)`依次提供1、2、3、4。每轮先把下一个元素赋给`number`，再把它加入`total`。循环变量表示本轮取得的元素，累加器保存此前各轮的计算结果。

| 轮次 | 本轮的`number` | 执行前的`total` | 执行后的`total` |
| --- | --- | --- | --- |
| 1 | 1 | 0 | 1 |
| 2 | 2 | 1 | 3 |
| 3 | 3 | 3 | 6 |
| 4 | 4 | 6 | 10 |

四轮结束后，`total`为10。**初始化语句`total = 0`需要放在循环之前，使累加器能够保留跨轮次的结果。**若把这条语句放进循环体，每轮都会先清零，最后只剩下最后一轮加入的数值。

### 5.2 range的端点与步长

| 写法 | 遍历到的值 |
| --- | --- |
| `range(5)` | 0、1、2、3、4 |
| `range(1, 6)` | 1、2、3、4、5 |
| `range(1, 6, 2)` | 1、3、5 |
| `range(5, 0, -2)` | 5、3、1 |
| `range(5, 0)` | 空序列 |

**非空的`range`从起点开始，排除终点，并按步长依次产生整数。**正步长使数值增大，负步长使数值减小。起止位置与步长方向不匹配时，序列为空，步长为0则会触发`ValueError`。

`range(0)`没有元素，循环体执行0次。如果某个名称只在循环体中赋值，空循环之后再使用它，就可能出现尚未绑定值的问题。循环外仍需使用的结果，应根据任务含义提前设置初始值。

### 5.3 遍历字符串、列表和文件

```python
for character in "Python":
    print(character, end=" ")
print()

for value in [12, "PY", 34]:
    print(value)
```

遍历字符串时，每轮取得一个字符。遍历列表时，每轮取得一个元素。上例列表依次提供整数12、字符串`"PY"`和整数34，循环变量`value`也会依次引用这些对象。

文件对象支持逐行遍历，每轮取得一行文本。下面的例子读取当前目录中的`sample.txt`，文件内容采用UTF-8编码。

```python
with open("sample.txt", encoding="utf-8") as file:
    for line in file:
        print(line, end="")
```

读到的行通常已经包含换行符，`end=""`让`print`直接输出这行内容，避免额外换行。`with`管理文件的使用过程，并在离开代码块时关闭文件。

<details>
<summary>术语解释：补充：文件对象与with语句</summary>

**文件对象**是程序读写文件时使用的对象，`open()` 在这里默认以文本读取方式打开文件。`encoding="utf-8"` 指定按UTF-8把文件字节读成文本。

`with ... as file` 使用**上下文管理**机制，安排进入和离开代码块时的资源处理。对这里的文件而言，离开代码块时会关闭它。此例只用于理解逐行遍历，文件读写的完整用法与自定义上下文管理器不在这七章中展开。

</details>

## 6. while 条件循环

```python
remaining = 3
while remaining > 0:
    remaining -= 1
    print(remaining)
```

程序每轮先判断`remaining > 0`，条件成立才进入循环体。由于先减1再输出，三轮的输出依次为2、1、0。第三轮结束后变量为0，下一次条件判断为假，循环结束。

分析`while`时，可以依次写出初始状态、进入条件和状态更新方式。上例每轮减1，使变量逐步接近退出条件。若改为`remaining += 1`，正数会越来越大，`remaining > 0`就会持续成立。

`while`的执行次数由条件决定。第一次判断就为假时，循环体执行0次。条件在后续更新中变为假时，循环经过有限次执行后结束。条件始终为真且没有跳出操作时，循环会持续运行。

循环次数已明确时，`for`通常更方便。等待用户提供满足要求的输入时，可以使用`while`。

```python
while True:
    try:
        number = int(input("请输入正整数 "))
    except ValueError:
        print("请重新输入整数")
        continue
    if number > 0:
        break
    print("输入值需要大于0")
print(f"已读取{number}")
```

这段程序把输入要求拆成两层检查。文本无法转换为整数时，`except`给出提示，并用`continue`进入下一轮。转换成功但数值小于等于0时，执行循环体末尾的提示。只有读到正整数，才通过`break`结束循环，并在循环之后输出已读取的数值。

> **学习提示**：这里先把 `continue` 理解为跳过本轮剩余语句，把 `break` 理解为结束所在循环。它们在 `for`、`while` 和嵌套循环中的具体范围见[本章第7节](第5章_程序的控制结构.md#7-breakcontinue-与循环-else)。

## 7. break、continue 与循环 else

### 7.1 跳转后的下一步

```python
for character in "PYTHON":
    if character == "T":
        continue
    print(character, end="")
```

输出为`PYHON`。读到`T`时，`continue`跳过本轮的输出语句，下一轮继续处理`H`。若改用`break`，循环会在读到`T`时结束，因此只输出前面的`PY`。

`for`执行`continue`后，会继续取得下一个元素。`while`执行`continue`后，会重新检查条件。如果必要的状态更新被放在`continue`之后，这次更新就会被跳过，程序可能反复处理同一个状态。

### 7.2 嵌套循环

```python
for row in range(2):
    for column in range(3):
        if column == 1:
            break
        print(row, column)
```

输出两行，分别为`0 0`和`1 0`。外层每轮进入内层循环，内层在`column`为0时输出，在它变为1时结束。随后外层继续下一轮。**`break`与`continue`只作用于所在的最内层循环**，需要按嵌套层次追踪它们的影响。

### 7.3 循环 else 与搜索

与`for`配对的`else`在遍历完所有元素后执行。与`while`配对的`else`在条件求值为假而正常结束循环时执行，第一次检查条件就为假时也会执行。**如果所在循环通过`break`结束，就跳过它的`else`。**`continue`只跳过一轮中的剩余操作，循环仍可能正常完成，因此不会直接取消`else`。函数返回或向外传播的异常则会让程序离开当前循环结构。

```python
values = [4, 8, 12]
target = 7
for value in values:
    if value == target:
        print("已找到")
        break
else:
    print("未找到")
```

目标为7时，没有元素满足相等条件，程序遍历完整个列表后输出`未找到`。把目标改为8时，第二轮输出`已找到`并执行`break`，随后跳过循环`else`。列表为空时，遍历直接完成，`else`仍会执行。

循环`else`也适合表达“检查完所有候选项，始终没有找到反例”。对于大于等于2的整数，只要2到自身前一个整数之间都找不到能整除它的数，就可以判定它为素数。

```python
number = 17
if number < 2:
    print("非素数")
else:
    for divisor in range(2, number):
        if number % divisor == 0:
            print("非素数")
            break
    else:
        print("素数")
```

找到一个因子就足以判定为非素数，此时通过`break`结束查找。所有候选因子都检查完后，循环`else`输出`素数`。当`number`为2时，`range(2, 2)`为空，遍历直接完成，同样会正确输出`素数`。

## 8. random 模块与可复现的随机过程

### 8.1 伪随机数与种子

`random`是Python标准库中的模块，提供伪随机数生成及随机选择等功能。导入模块后，可以用`random.函数名(...)`调用其中的函数。

<details>
<summary>术语解释：伪随机数与随机种子</summary>

**伪随机数**由确定的算法生成，序列表现出随机性。**随机种子**（seed）是初始化生成器状态的数据。它让同一环境中的同一生成过程可以重现，适合检查和比较实验。固定种子不意味着连续调用时每次都返回同一个数。

</details>

```python
import random

random.seed(10)
first = random.random()
random.seed(10)
second = random.random()
print(first == second)
```

输出为`True`。伪随机数生成器按算法更新内部状态，再根据状态产生数值。种子负责初始化这一过程。**在相同环境和调用顺序下，重新设置相同种子，会重复同一序列的开头。**上例两次取值之前都重设了种子，因此取得相同的第一个值。

如果只设置一次种子，然后连续调用`random()`，每次调用都会推进生成器状态，通常得到不同的后续值。省略种子时，Python会优先使用操作系统提供的随机源，在相应随机源不可用时再使用系统时间。复现实验时，需要同时保持种子和随机函数的调用顺序一致。

### 8.2 常用函数与边界

| 函数 | 行为 | 重点 |
| --- | --- | --- |
| `random.random()` | 返回大于等于0且小于1的浮点数 | 右端点1排除 |
| `random.randint(a, b)` | 从整数a到b中选择 | 两个端点都包含 |
| `random.randrange(m, n, k)` | 从`range(m, n, k)`中选择 | 终点n排除 |
| `random.getrandbits(k)` | 产生k个随机比特构成的非负整数 | 范围为0到`2**k - 1` |
| `random.uniform(a, b)` | 在两个端点间生成浮点数 | 浮点舍入影响终点能否取到 |
| `random.choice(seq)` | 从非空序列取一个元素 | 空序列会触发`IndexError` |
| `random.shuffle(values)` | 原地打乱可变序列 | **修改原序列并返回`None`** |

`getrandbits(4)`对应4个随机比特的组合，数值范围为0到15。组合的高位可以为0，因此结果的二进制有效位数可能少于4。`randrange(10, 100, 10)`的候选值与相应的`range`一致，只能从10、20、……、90中选取。

`shuffle`直接修改传入列表的排列顺序，因此后续应继续使用这个列表。若把函数返回值赋给另一个名称，得到的是`None`。

```python
import random

values = [1, 2, 3, 4]
result = random.shuffle(values)
print(result)
print(sorted(values))
```

第一行输出`None`。第二行先排序再显示，输出`[1, 2, 3, 4]`，可以核对打乱前后的元素是否一致。具体排列由生成器状态决定，也可能恰好与原排列相同。若要打乱字符串中的字符，可以先把字符串转换为列表，再操作这个可变序列。

## 9. 圆周率计算的两个过程

### 9.1 按公式累加

**BBP公式**以Bailey、Borwein和Plouffe三位研究者的姓氏首字母命名，它用级数表示圆周率。**级数**表示把数列中的项依次相加，这里的表达式包含无限多个项。实际程序只计算有限项，因此用前N项的和近似圆周率。下面用求和的形式表示这条公式，`k`从0开始逐项增加。

```text
pi = sum((1 / 16**k) * (
    4 / (8*k + 1) - 2 / (8*k + 4)
    - 1 / (8*k + 5) - 1 / (8*k + 6)
) for k = 0, 1, 2, ...)
```

把公式写成程序时，先把累加器设为0，再让循环依次计算并加入第0项到第N-1项。

```python
pi_estimate = 0.0
terms = 20
for k in range(terms):
    term = (1 / 16 ** k) * (
        4 / (8 * k + 1)
        - 2 / (8 * k + 4)
        - 1 / (8 * k + 5)
        - 1 / (8 * k + 6)
    )
    pi_estimate += term
print(f"{pi_estimate:.15f}")
```

程序先计算当前`k`对应的`term`，再把它加入`pi_estimate`。随着`k`增大，分母中的`16**k`迅速增长，后续项越来越小。只取有限项会产生截断误差，使用浮点数还会产生舍入误差。精度受到浮点表示限制后，继续增加项数通常无法继续改善结果。

较长的表达式放在圆括号内，可以分行书写，各行共同组成一次完整计算。源代码中的减号使用ASCII字符`-`。

### 9.2 蒙特卡罗撒点法

**蒙特卡罗方法**（Monte Carlo method）通过随机抽样估计数值或概率。下面的撒点实验就是一个例子。**均匀抽样**表示等面积区域被命中的机会相同，**独立抽样**表示一次抽样结果不影响其他次抽样的分布。

在第一象限边长为1的正方形中均匀撒点，坐标满足`0 <= x < 1`、`0 <= y < 1`。以原点为圆心、半径为1作圆，正方形内满足`x*x + y*y <= 1`的部分恰好是四分之一圆。

正方形面积为1，四分之一圆面积为`pi / 4`。在均匀撒点的模型下，命中四分之一圆的概率等于面积之比，即`pi / 4`。将命中次数记为`hits`，总次数记为`darts`，就可以用`hits / darts`估计这一概率，从而得到**`pi ≈ 4 * hits / darts`**。

```python
import random
from time import perf_counter

random.seed(2026)
darts = 100000
hits = 0
start = perf_counter()
for _ in range(darts):
    x = random.random()
    y = random.random()
    if x * x + y * y <= 1:
        hits += 1
pi_estimate = 4 * hits / darts
elapsed = perf_counter() - start
print(f"圆周率近似值为{pi_estimate:.6f}")
print(f"耗时约{elapsed:.4f}秒")
```

每轮生成一对坐标，检查平方和是否小于等于1，命中时将`hits`增加1。直接比较平方和可以省去开平方。循环变量`_`表示程序只使用重复次数，不使用本轮编号。`darts`需要为正整数，才能得到有意义的命中比例。

**在独立、均匀抽样的理想模型下，记样本数为`N`，随机误差规模约随`1 / sqrt(N)`下降。**要把这一规模缩小到原来的十分之一，样本数通常需要增加到约100倍。一次实验的误差仍可能上下波动，增加少量样本并不保证这一回就更接近圆周率。固定种子可以复核同一次抽样过程。

BBP级数利用圆周率的特定公式，少量项就能取得较高精度。撒点法则展示了把面积关系转成概率，再通过随机实验估计的过程，这种思路还可以用于其他图形的面积估计。测量和比较程序耗时时，需要记录计算规模、运行环境和输出方式，使结果对应到明确的实验条件。
