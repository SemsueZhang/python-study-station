# 第2章 基本语法元素

带单位的温度转换包含一个完整的数据处理过程。程序先读取文本，从中取出数值和单位，再按单位选择公式，最后输出符合格式要求的结果。变量负责引用数据，表达式完成计算，分支决定执行路径，函数调用完成输入、转换与输出。理解这些成分怎样配合，就能逐步读懂一个小程序。

学习时，可以沿着“数据怎样进入程序、在程序中怎样变化、最终怎样显示”的顺序追踪。除了掌握命名、赋值和缩进，还要能根据输入格式选择字符串的取值方式，区分数值转换与表达式求值，并把同样的处理方法用于货币换算和圆的计算。

> **学习提示**：本章重点是读懂并修改温度转换程序。数字类型与运算在第3章展开，字符串索引、切片和格式化在第4章展开，分支与循环在第5章展开。函数目前只需会调用，定义、形参和返回值的完整规则见第6章。示例暂未处理的输入错误，会在[第5章第3节](第5章_程序的控制结构.md#3-异常处理的执行路径)学习处理方法。

## 1. 从最小程序认识表达式与语句

**表达式**是能够求得一个值的代码，例如 `25`、`2 + 3`。**语句**描述程序要执行的动作，例如赋值、分支和导入。表达式常作为语句的一部分，先计算出结果，再由语句决定怎样使用这个结果。

下面用三行代码完成赋值、温度计算和输出。

```python
temperature = 25
fahrenheit = temperature * 1.8 + 32
print(fahrenheit)
```

程序从上到下运行。第一行把整数25赋给 `temperature`。第二行先读取这个值，计算 `25 * 1.8 + 32`，得到77.0，再将结果赋给 `fahrenheit`。第三行调用 `print()`，把 `fahrenheit` 所引用的值输出到控制台。

第二行的 `temperature * 1.8 + 32` 是表达式，整条赋值语句则把名称 `fahrenheit` 绑定到求得的数值对象。调用函数时实际提供的输入称为实参，例如 `print(fahrenheit)` 把变量当前引用的对象传给 `print()`。**函数调用得到的结果称为返回值，执行中还可能产生向屏幕输出文本等操作。**阅读时，可以按下表识别各个成分。

| 成分 | 示例 | 作用 |
| --- | --- | --- |
| 变量名 | `temperature` | 引用一个数据对象 |
| 字面量 | `25`、`1.8`、`"C"` | 在代码中直接写出的数据 |
| 运算符 | `*`、`+` | 指定要进行的运算 |
| 赋值符号 | `=` | 将右侧计算结果绑定到左侧名称 |
| 函数调用 | `print(fahrenheit)` | 使用函数完成一项功能 |

编辑器常用不同颜色显示名称、字符串和关键字，这称为语法高亮。配色可以帮助辨认代码，但会随编辑器和主题改变。检查程序时，仍需核对实际字符、语法和执行顺序。

## 2. 变量、命名、保留字与赋值

### 2.1 变量名引用数据

变量可以先理解为程序中用于引用数据的名称。Python中的数据以对象形式存在，赋值把名称与对象关联起来，这种关联称为**绑定**。之后使用变量名，就能访问它当前引用的对象。再次赋值时，名称可以转而引用另一个对象。

```python
celsius = 0
fahrenheit = celsius * 1.8 + 32
celsius = 100
print(fahrenheit)  # 32.0
```

执行第二行时，`celsius` 为0，因此 `fahrenheit` 得到32.0。第三行把 `celsius` 改为100，但没有重新执行第二行，所以第四行仍输出32.0。若要得到与100摄氏度对应的华氏温度，需要再次计算转换表达式。

**普通赋值只在执行到这条语句时计算一次右侧。**变量之间是否继续保持某个关系，取决于之后是否再次执行相应计算。阅读含有多次赋值的程序时，应记录每条语句执行后的值，避免把先前的计算误认为会自动持续更新。

### 2.2 标识符的基本规则

<details>
<summary>术语解释：ASCII与Unicode</summary>

**ASCII**（American Standard Code for Information Interchange，美国信息交换标准代码）为128种字符规定编码，包括英文字母、数字和部分符号。**Unicode**为不同文字和符号提供统一的字符编号，能够覆盖汉字等更多字符。

这里先知道Python名称允许部分非ASCII字符即可。码点与文本编码的区别见[第4章第3节](第4章_字符串与time库.md#3-字符串不可变性与基本操作)。

</details>

**标识符**是变量、函数等程序成分使用的名称。编写常见标识符时，应遵守下面的规则。

- 可以使用英文字母、数字和下划线等允许的字符。
- 首字符可以是字母或下划线，不能是数字。
- 大小写敏感，`temp`、`Temp` 和 `TEMP` 是不同名称。
- 保留字不能直接用作普通变量名，例如 `if`、`else` 和 `import`。
- Python也允许符合Unicode标识符规则的非ASCII字符，包括许多中文字符。采用含义清楚的英文名称与下划线，便于统一阅读和交流。

| 名称 | 是否符合基本语法规则 | 说明 |
| --- | --- | --- |
| `temperature` | 是 | 含义清晰 |
| `temp_2` | 是 | 数字出现在后续位置 |
| `_result` | 是 | 下划线可以位于开头 |
| `2temp` | 否 | 以数字开头 |
| `temp-value` | 否 | 连字符在这里会被理解为减号 |
| `if` | 否 | 属于保留字 |
| `If` | 是 | 与保留字大小写不同，但容易混淆 |

名称既要合法，也要方便理解。`a` 符合语法规则，用 `radius` 表示半径则能直接体现含义。多个单词组成名称时，可以用下划线分隔，例如 `student_count`，同时在同一程序中保持一致风格。

### 2.3 保留字与内置名称

**保留字**也称**关键字**，具有语言规定的含义。例如，`if`、`elif`、`else` 组织分支，`in` 参与成员判断，`import`、`from`、`as` 用于导入。这些词在相应语法中承担固定作用。

`input`、`print`、`float` 等是Python预先提供的内置名称，无需导入即可使用。其中，`input()`、`print()` 是内置函数，`float` 是可以用于数值转换的内置类型。普通赋值能够覆盖这些名称。例如执行 `print = 3` 后，当前代码中的 `print` 就引用整数3，接着再写 `print(...)` 会因整数无法调用而出错。给变量命名时，应避开这些常用内置名称。

关键字列表可能随Python版本调整。Python还存在只在特定语法位置发挥关键字作用的软关键字。学习基本语法时，可以先把当前程序中使用的词与对应结构联系起来，再逐步认识更多语法。

例如 `match` 和 `case` 在结构模式匹配语句中是软关键字，在其他允许的位置仍可作为普通名称。结构模式匹配不在这七章中展开，这里只需知道它与不能用作普通标识符的保留关键字有区别。

### 2.4 赋值、相等判断与解包赋值

**`=` 用于赋值，执行时先计算右侧，再更新左侧名称的绑定。**`==` 用于相等比较，得到 `True` 或 `False`，分别表示判断成立或不成立。

```python
x = 5
print(x == 5)  # True
x = x + 1
print(x)       # 6
```

执行 `x = x + 1` 时，右侧先读取旧值5并加1，得到6，然后才更新左侧的 `x`。因此，同一个名称出现在等号两侧并不矛盾，它表达的是一次按旧值计算新值的更新。

Python还支持**解包赋值**，把右侧的一组值分别交给左侧的多个名称。常见的 `a, b = b, a` 也被称为同步赋值，关键是先求出整个右侧，再依次绑定左侧名称。

```python
a, b = 2, 5
a, b = b, a
print(a, b)  # 5 2
```

交换时，右侧先读取旧的 `b` 和 `a`，得到5与2，再分别赋给左侧的 `a` 和 `b`。两个旧值都先参与求值，因此交换不会丢失其中一个值。

## 3. 数据类型与字符串拆分

### 3.1 相同外观可能具有不同类型

**数据类型**决定对象表示什么，以及能够参与哪些操作。看见一段数据时，应同时辨认它的值和类型。数字123与文本 `"123"` 显示时很相似，能够进行的计算却不同。

| 写法 | 类型 | 示例含义 |
| --- | --- | --- |
| `123` | 整数 `int` | 一个整数值 |
| `12.3` | 浮点数 `float` | 一个近似实数值 |
| `"123"` | 字符串 `str` | 由三个字符组成的文本 |
| `["F", "f"]` | 列表 `list` | 按顺序组织的两个字符串 |
| `True`、`False` | 布尔值 `bool` | 判断结果的真与假 |

**字符串**是有序的字符序列，用一对匹配的引号界定。源代码中的引号标明字符串从哪里开始、在哪里结束，通常不属于字符串内容。因此，`print("123")` 显示的是三个字符123。

```python
print(12 + 3)       # 15
print("12" + "3")   # 123
print(float("12") + 3)  # 15.0
```

第一行把两个整数相加，得到15。第二行把两段文本连接起来，得到字符串 `"123"`。第三行先把文本 `"12"` 转为浮点数12.0，再与整数3相加，得到15.0。**相同的加号会根据操作数类型执行相应操作。**

### 3.2 字符串索引

**索引**是字符在字符串中的位置编号。正向编号从0开始，负向编号从末尾的-1开始。使用 `text[index]` 可以取得某个位置的字符。

对于 `text = "82F"`，字符与位置如下。

| 字符 | `8` | `2` | `F` |
| --- | --- | --- | --- |
| 正向索引 | 0 | 1 | 2 |
| 负向索引 | -3 | -2 | -1 |

在这个字符串中，`text[0]` 取第一个字符 `"8"`，`text[-1]` 取末尾字符 `"F"`。**索引访问要求指定位置确实存在。**空字符串没有末尾字符，因此使用 `[-1]` 会产生索引错误。

### 3.3 字符串切片

**切片**用于取得字符串的一部分，基础形式为 `text[start:stop]`。这里按默认的正向步长取值，包含起点，排除终点。省略起点表示从开头开始，省略终点表示一直取到结尾。

```python
text = "82F"
print(text[0:-1])  # 82
print(text[:-1])   # 82
print(text[-1])    # F
```

本例中，切片终点-1指向F所在的位置。**由于终点不被包含，`text[0:-1]` 取得前面的字符8和2，组成字符串 `"82"`。**省略起点后的 `text[:-1]` 含义相同。

解析输入前，应先确定单位位于开头还是末尾，以及占几个字符。不同约定对应不同的索引与切片。

| 输入约定 | 输入示例 | 单位或币种 | 数值文本 |
| --- | --- | --- | --- |
| 单字符后缀 | `82F` | `text[-1]` | `text[:-1]` |
| 单字符前缀 | `C82` | `text[0]` | `text[1:]` |
| 三字符前缀 | `RMB100` | `text[:3]` | `text[3:]` |

这些切片得到的结果仍然是文本。例如，`text[:-1]` 可以得到 `"82"`，再执行 `float("82")` 才得到数值82.0。拆分负责确定文本范围，类型转换负责把数值文本变成可计算的数据。

> **学习提示**：这里先掌握默认向前截取、排除终点的用法。负步长、省略边界和越界行为见[第4章第2节](第4章_字符串与time库.md#2-索引与切片)。

### 3.4 成员判断 `in`

**成员判断**用于检查某个值是否出现在指定对象中。例如，使用 `in` 可以判断温度单位是否属于允许的写法。

```python
unit = "f"
print(unit in ["F", "f"])  # True
print(unit in ["C", "c"])  # False
```

对列表进行成员判断时，左侧的值与列表元素比较。`unit` 为 `"f"`，在列表 `["F", "f"]` 中能找到相等元素，因此第一个结果为 `True`。在 `["C", "c"]` 中找不到，所以第二个结果为 `False`。这种判断结果可以直接作为分支条件。

## 4. 分支、缩进、注释与续行

### 4.1 分支按条件选择路径

**分支**根据条件的真假选择执行哪一组语句。使用 `if`、`elif`、`else` 组成一组分支时，程序从上向下检查条件，选中一条路径后就跳过同组后面的分支。

```python
number = -2
if number > 0:
    print("positive")
elif number < 0:
    print("negative")
else:
    print("zero")
```

这里 `number` 为-2。第一个条件 `number > 0` 不成立，程序继续检查 `number < 0`。第二个条件成立，执行它下面的输出语句，显示 `negative`，随后跳过 `else`。如果数值为0，两个条件都不成立，才会执行最后的分支。

- `if` 开始条件判断。
- `elif` 用于继续检查其他条件，可以出现零次或多次。
- `else` 用于处理前面条件均不成立的情况，可以省略。
- 每个分支头末尾写英文冒号，所属代码块增加缩进。

`else` 承接的是前面条件全部不成立的情况，因此后面不再写条件。还要留意分支是否属于同一组。**如果连续写几条独立的 `if`，程序会分别检查每条条件，同一次执行中可能有多条成立。**

> **学习提示**：这里先能按顺序跟踪 `if-elif-else`。逻辑运算与条件真假见[第5章第1节](第5章_程序的控制结构.md#1-顺序执行与条件计算)，区间覆盖和多分支设计见[第5章第2节](第5章_程序的控制结构.md#2-分支结构与区间覆盖)。

### 4.2 缩进表达代码块所属关系

**代码块**是一组共同从属于某个结构的语句。Python用行首缩进表示这种所属关系，同一代码块中的语句处于相同缩进层次。

```python
number = 2
if number > 0:
    print("positive")
    print("inside the branch")
print("finished")
```

前两个 `print()` 都比 `if` 多缩进一层，属于这个分支的代码块。最后一行与 `if` 对齐，已经回到外层。数值为2时，三条输出都会执行。如果条件不成立，前两条被跳过，正常执行到外层最后一行时仍会输出 `finished`。

**每层使用4个空格是通用风格约定。**语法要求则是正确表示层次，并保持同一代码块的缩进一致，其他一致的缩进宽度也可能合法。编辑时可以让工具统一插入空格，避免Tab与空格混用。即使屏幕上看似对齐，不同空白字符也可能造成缩进错误。

### 4.3 注释与字符串

**注释**用于帮助人理解代码。字符串之外的 `#` 开始一段行内注释，直到该行结束，普通注释内容不作为程序语句执行。注释可以独占一行，也可以跟在语句后面。

```python
# Convert Celsius to Fahrenheit.
celsius = 25
fahrenheit = celsius * 1.8 + 32  # Apply the conversion formula.
```

三引号用来定义字符串，可以让字符串内容跨越多行。放在模块、函数或类主体开头的字符串，可以作为文档字符串说明用途。**一个单独放置的字符串表达式即使没有可见输出，也仍按字符串语法处理。**需要写多行普通注释时，可以连续写多行 `#`。

<details>
<summary>术语解释：文档字符串（docstring）</summary>

**文档字符串**是模块、函数或类的第一条语句位置上的字符串字面量，用来说明用途，可以由帮助工具读取。三引号只是字符串的书写形式，不会自动让任何位置上的字符串变成文档字符串。此处先辨认注释和字符串，函数定义见第6章。

</details>

当 `#` 位于字符串内部时，它是字符串内容。例如，`print("A#B")` 会输出 `A#B`。

### 4.4 长语句的续行

括号内通常可以自然换行，程序仍将其视为同一个表达式。

```python
total = (
    10 + 20
    + 30
)
print(total)  # 60
```

还可以在行尾使用反斜线继续语句。反斜线需要位于该行末尾，后面不能继续放注释等内容。阅读和编写较长表达式时，括号内换行通常更容易保持清楚的结构，也便于增加行内说明。

源代码中的一条语句可以占多行，最终显示几行则由输出内容决定。要让文本显示时换行，可以在字符串中使用 `\n`，也可以多次调用默认末尾换行的 `print()`。

## 5. 基本输入与数值转换

### 5.1 `input()` 返回字符串

`input()` 从控制台读取用户输入的一行文本。调用时可以提供提示字符串，程序显示提示后等待输入，用户按回车确认后再继续执行。

```python
text = input("Enter a number: ")
print(text)
```

上面的程序先显示 `Enter a number: `，再把输入结果赋给 `text`。`input()` 返回时会去掉行末用于结束本次输入的换行，第二行将取得的文本输出。

**即使输入12，`text` 得到的仍是字符串 `"12"`。**控制台接收的内容与源代码中的字符串表示需要分开理解。输入姓名等文本时，直接键入内容即可。如果额外键入一对引号，那两个引号也会被读入。

`input()` 会保留输入中的一般空白。需要去掉两端空格等空白字符时，可以使用 `text.strip()`。这种“对象加点号再调用”的写法表示使用字符串提供的方法，它返回处理后的字符串。若希望变量保存处理结果，应写成 `text = text.strip()`。

> **学习提示**：`strip()` 在这里用于清理两端空白。带参数时的删除规则，以及其他字符串方法，见[第4章第4节](第4章_字符串与time库.md#4-常用字符串方法)。

### 5.2 `int()` 与 `float()`

要把输入用于数值计算，需要按数据含义进行类型转换。`int` 和 `float` 是内置类型，调用它们可以完成相应转换。`int()` 把合法整数文本转为整数，`float()` 把合法的整数或小数等数值文本转为浮点数。

```python
count = int(input())
price = float(input())
print(count * price)
```

这里约定第一行输入合法整数，第二行输入合法数值。执行 `int(input())` 时，内层 `input()` 先返回字符串，外层 `int()` 再把它作为实参转换为整数，最后赋给 `count`。`float(input())` 的求值顺序相同。例如输入2和12.5，程序会用整数2乘浮点数12.5，输出25.0。

`int("12")` 得到整数12，`float("12.5")` 得到浮点数12.5。`int("12.5")` 则会转换失败，因为该文本带有小数部分。转换操作应与输入含义配套。**即使转换成功，还要根据任务检查数值范围，例如读取身高后仍需判断它是否大于0。**

### 5.3 `eval()` 进行表达式求值

`eval()` 将字符串作为Python表达式求值，返回表达式的值。

```python
print(eval("1"))           # 1
print(eval("1 + 2"))       # 3
print(eval('"1 + 2"'))     # 1 + 2
```

第一行把文本 `"1"` 当作整数字面量求值，得到1。第二行把 `"1 + 2"` 当作加法表达式求值，得到3。第三行外层单引号界定传入的字符串，其内容还包含一对双引号，因此被求值的表达式是字符串字面量，结果为文本 `"1 + 2"`。

函数调用也属于表达式。例如，`eval('print("Hello")')` 会执行 `print("Hello")`，因此屏幕上显示 `Hello`。与此同时，内部 `print()` 的返回值为 `None`，这个对象也成为 `eval()` 的返回值。**`eval()` 的返回值与执行过程中产生的屏幕输出，应分别判断。**

<details>
<summary>术语解释：None与返回值</summary>

**`None`**是Python中表示“没有具体结果”等含义的特殊对象。`print()` 完成屏幕输出后返回 `None`，这与“输出的文字就是返回值”不同。它也不等于数字0或空字符串。`None` 见[第3章第4节](第3章_数字类型与运算.md#4-复数布尔值整数序列与空值)，输出与返回的区别见[第6章第5节](第6章_函数定义与调用.md#5-返回值与屏幕输出)。

</details>

| 写法 | 目的 | 对 `"1+2"` 的处理 |
| --- | --- | --- |
| `int(text)` | 将合法整数文本转为整数 | 转换失败 |
| `float(text)` | 将合法数值文本转为浮点数 | 转换失败 |
| `eval(text)` | 按Python表达式规则求值 | 得到3 |

读取普通温度值时，只需把合法数值文本转为浮点数，调用内置类型 `float` 完成转换即可。`eval()` 是内置函数，适用于确实需要解释Python表达式，并且能够理解和控制其内容的情形。直接对任意外部输入求值，可能执行文本中的调用等操作。选择输入处理方式时，应先确定要接受数值文本，还是要接受表达式。

## 6. 输出与格式化显示

### 6.1 `print()` 的基本行为

`print()` 可以输出一个或多个对象。默认情况下，多个对象之间加一个空格，末尾换行。

```python
print("A", "B")
print("A", "B", sep="-")
print("A", end="")
print("B")
```

第一次调用输出 `A B`，两个对象之间采用默认空格。第二次调用通过 `sep="-"` 输出 `A-B`。第三次调用把 `end` 设为空字符串，输出A后停留在同一行，第四次调用接着输出B并换行。因此，四次调用最终显示三行，最后一行为 `AB`。

`sep` 控制同一次调用中多个对象之间插入什么，`end` 控制一次调用结束时追加什么。它们是 `print()` 中用于接收这些设置的形参。**调用时用 `sep="-"` 这样的 `名称=值` 写法，把具体输入交给指定的形参，称为关键字传递。**`sep="-"` 这一项就是关键字实参，`end=""` 也是同样的用法。把对象之间的分隔和调用结束后的内容分开，就能理解多次输出怎样连接。

<details>
<summary>术语解释：形参、实参与关键字实参</summary>

**形参**（形式参数）是函数定义中用来接收输入的名称，**实参**（实际参数）是调用时提供的值或表达式。`sep="-"` 按形参名称提供实参，称为**关键字实参**。这里的“关键字”不表示 `sep` 是Python保留字。

位置传递、关键字传递和默认值的完整规则见[第6章第3节](第6章_函数定义与调用.md#3-形参与实参怎样对应)。

</details>

### 6.2 模板字符串与替换字段

**格式化**用于把固定文字与变化的数据组合成所需的显示形式。模板字符串中的花括号及其内容称为**替换字段**（replacement field），可以把它理解为等待填值的占位位置。字符串的 `format()` 方法按对应关系填入实参。

```python
celsius = 12.345
message = "Result {:.2f}C".format(celsius)
print(message)
```

这个模板的固定部分为 `Result ` 和 `C`，中间的 `{:.2f}` 是一个带格式要求的替换字段。调用模板字符串的 `format()` 方法，把 `celsius` 当前引用的数值作为实参传入。该方法返回填好替换字段的字符串，将它赋给 `message` 后，再调用 `print()` 输出。

`{:.2f}` 中的 `f` 表示定点数显示，`.2` 表示显示小数点后两位。本例输出 `Result 12.35C`。即使数值的小数部分不足两位，也会补足，例如32.0会显示成 `32.00`。

> **学习提示**：现在先会使用 `{}` 和 `{:.2f}`。字段编号、填充、对齐和其他显示格式见[第4章第5节](第4章_字符串与time库.md#5-字符串格式化)。

**这次方法调用返回用于输出的字符串，没有改变名称 `celsius` 的绑定，它仍引用原来的数值12.345。**计算与显示应分别处理，通常先完成需要的数值计算，再在最终输出处决定小数位数。

模板中有多个替换字段时，可以按实参顺序逐个填入。这里使用位置传递，把半径作为第一个实参，把面积作为第二个实参，因此两个替换字段分别取得这两个值，并只对面积要求两位小数。

```python
radius = 2
pi = 3.1415
print("r={}, area={:.2f}".format(radius, pi * radius * radius))
```

### 6.3 输出内容中的换行

字符串中的 `\n` 表示一个换行字符。它控制显示文本在什么位置进入下一行。

```python
print("Hello\nWorld")
```

这次调用会先输出 `Hello`，换行后输出 `World`，最后再追加默认的行末换行。

如果要让每个字符各占一行，可以遍历字符串。遍历就是按顺序逐项取出元素，下面的 `for` 每次取得一个字符，再执行一次输出。

```python
for ch in "Hello":
    print(ch)
```

变量 `ch` 依次引用 `H`、`e`、`l`、`l`、`o`。缩进的 `print(ch)` 随每次取值执行，默认末尾换行，因此一共显示五行。

> **学习提示**：这是 `for` 遍历循环的预览，只需看懂“取一个字符、输出一次”。完整语法与循环变量的变化见[第5章第5节](第5章_程序的控制结构.md#5-for-遍历循环)。

### 6.4 交互提示与评测输出

面向用户的交互程序常用“请输入”等文字说明操作。自动评测题则通常规定了完整输出格式。**如果只要求一个数值或带单位结果，额外的提示文字也可能导致结果不符合要求。**写程序前，应先确定输出交给人阅读，还是交给评测系统检查。

提交前应检查输入行数、单位位置、输出顺序、大小写、小数位数、空格和换行。计算中使用的常量也应与题目约定一致。例如题目指定圆周率为3.1415时，应使用这个值，以便计算过程与预期结果保持一致。

## 7. 完整拆解温度转换程序

### 7.1 先确定输入输出协议

**输入输出协议**是对数据格式和结果形式的约定。这里采用单字符单位后缀，输入为非空且数值部分合法的字符串，例如 `82F`、`28c`。数值应当有限，且转换过程中的中间量和结果都能用有限浮点数表示。最后一个字符表示单位，前面的字符表示数值。输出则保留两位小数，并在末尾显示转换后的大写单位。

<details>
<summary>术语解释：有限数、无穷大与NaN</summary>

**有限数**不包括正负无穷大和 `NaN`。浮点数还可以表示 `inf`（infinity，无穷大）和 `nan`（Not a Number，非数）。它们能够由 `float("inf")`、`float("nan")` 这样的转换得到，所以转换成功不等于输入符合温度范围。

这里先按有限数输入约定阅读程序。浮点表示见[第3章第3节](第3章_数字类型与运算.md#3-浮点数与近似计算)，用 `math.isfinite()` 检查非有限值的例子见[第5章第4节](第5章_程序的控制结构.md#4-bmi实例的边界分析)。

</details>

| IPO部分 | 本例约定 |
| --- | --- |
| 输入 | 温度数值加单字符单位后缀 |
| 处理 | 根据末尾单位选择转换公式 |
| 输出 | 转换后的数值与单位，保留两位小数 |

### 7.2 理解转换公式

用C表示摄氏温度，用F表示华氏温度。两种温标采用线性对应关系，0摄氏度对应32华氏度，100摄氏度对应212华氏度。这个区间中，摄氏温度增加100，华氏温度增加180，因此每增加1摄氏度，对应增加1.8华氏度。

由摄氏温度求华氏温度，先按比例乘1.8，再加上起点偏移32，得到 `F = 1.8 * C + 32`。反向转换时，先去掉偏移，再还原比例，得到 `C = (F - 32) / 1.8`。这样可以从对应点和变化比例理解公式，而不只记忆符号。

括号决定先做减法。若将第二个公式误写成 `F - 32 / 1.8`，就会先计算除法，转换结果随之改变。

### 7.3 基础版本

```python
text = input("Enter a temperature, such as 82F: ")
unit = text[-1]

if unit in ["F", "f"]:
    celsius = (float(text[:-1]) - 32) / 1.8
    print("{:.2f}C".format(celsius))
elif unit in ["C", "c"]:
    fahrenheit = float(text[:-1]) * 1.8 + 32
    print("{:.2f}F".format(fahrenheit))
else:
    print("Invalid unit")
```

读取后，`text[-1]` 取得单位，分支决定采用哪条公式。只有进入相应的转换分支后，程序才用 `float(text[:-1])` 把前面的文本变成浮点数，随后计算并格式化输出。单位选择和数值转换发生在不同位置，阅读时可以沿着这两个步骤分别核对。

以输入 `82F` 为例，按执行顺序追踪。

1. `text` 保存字符串 `"82F"`。
2. `unit` 保存 `"F"`。
3. 第一个成员判断成立。
4. `text[:-1]` 得到 `"82"`，`float()` 得到82.0。
5. 计算 `(82.0 - 32) / 1.8`。
6. 将结果格式化成 `27.78C` 并输出。
7. 跳过这一组后面的 `elif` 和 `else`。

输入 `28c` 时进入第二个分支，计算并输出 `82.40F`。输入 `82X` 时，两个单位判断都不成立，输出 `Invalid unit`。

### 7.4 输入约定与程序实际能力

基础版本依赖前面约定的输入格式和数值范围。空输入没有末尾字符，会在 `text[-1]` 处产生索引错误。`abcF` 虽然通过了单位检查，却会在转换 `float("abc")` 时失败。因此，检查单位只能确认一个部分的格式，还需要单独考虑空输入和数值文本。

下面先清理两端空白，再检查是否为空，确保只有存在字符时才访问末尾位置。

```python
text = input().strip()
if text == "":
    print("Empty input")
elif text[-1] in ["F", "f"]:
    value = float(text[:-1])
    print("{:.2f}C".format((value - 32) / 1.8))
elif text[-1] in ["C", "c"]:
    value = float(text[:-1])
    print("{:.2f}F".format(value * 1.8 + 32))
else:
    print("Invalid unit")
```

如果用户只输入空格，调用字符串的 `strip()` 方法后也会得到空字符串，因此进入 `Empty input` 分支。**数值部分仍依赖合法输入约定，`abcF` 等文本依然会转换失败。**若要在失败后继续给出友好提示，需要使用异常处理捕获转换错误。非有限值和计算范围还需要通过数值检查处理，前面的程序没有进行这两项检查。阅读程序时，应明确哪些情况已经由代码检查，哪些仍由输入条件保证。

> **学习提示**：**异常**是操作不能按正常路径完成时产生的信号，**捕获**是用处理语句接住它并安排后续动作。`try/except` 的写法见[第5章第3节](第5章_程序的控制结构.md#3-异常处理的执行路径)，非有限值与计算范围检查见[第5章第4节](第5章_程序的控制结构.md#4-bmi实例的边界分析)。

### 7.5 输入格式变化时同步修改解析

如果单位改到开头，如 `C12.34`，应使用 `text[0]` 取单位，用 `text[1:]` 取数值文本。

```python
text = "C12.34"
unit = text[0]
value = float(text[1:])
print(unit, value)  # C 12.34
```

数值提取正确后，还要核对输出格式。若要求四位小数，就使用 `{:.4f}`。从后缀格式改为前缀格式时，应同时检查单位位置、数值切片、转换方向和显示要求，避免只修改其中一处。

## 8. 迁移到货币与圆的计算

以下两个示例都约定数值文本合法、输入数值有限，且计算过程中的中间量和结果都能用有限浮点数表示。圆的半径还需要是非负数。

### 8.1 三字母币种前缀

货币换算同样需要先辨认单位，再提取数值。这里约定前三个字符是币种，`RMB` 表示人民币，`USD` 表示美元，并采用1美元兑换6.78元人民币的固定比例。6.78只作为本例的计算常量。实际兑换还会涉及日期、报价和其他规则，使用数据时需要另行明确这些条件。

```python
text = input()
code = text[:3]
value = float(text[3:])

if code == "RMB":
    print("USD{:.2f}".format(value / 6.78))
elif code == "USD":
    print("RMB{:.2f}".format(value * 6.78))
else:
    print("Invalid currency")
```

输入 `RMB100` 时，`text[:3]` 得到 `"RMB"`，`text[3:]` 得到 `"100"`。把数值转为100.0后，用人民币金额除以6.78元人民币每美元，得到美元金额，保留两位小数后显示 `USD14.75`。反向换算时，每美元对应6.78元人民币，因此使用乘法。把单位写在心里或草稿上，可以检查乘除方向。

### 8.2 两行输出圆周长和面积

给定半径后，圆周长为 `2 * pi * radius`，圆面积为 `pi * radius * radius`。两个结果可以共用输入和圆周率常量，再分别安排输出。

```python
radius = float(input())
pi = 3.1415
circumference = 2 * pi * radius
area = pi * radius * radius
print("{:.2f}".format(circumference))
print("{:.2f}".format(area))
```

这里约定输入为合法非负半径，先输出周长，再输出面积，每个结果占一行。如果题目要求中文标签，则需把标签按题目格式加入模板。

变量 `circumference` 和 `area` 分别保存周长与面积，便于在输出前检查结果。若半径为2，按本例的常量计算，周长与面积都为12.566，两行均显示12.57。这只是该半径下的数值巧合，两条公式表达的量和单位仍然不同。

## 9. 模块导入的三种基本方式

模块是组织Python功能的单元，库通常包含一个或多个模块。**标准库模块提供的函数需要通过导入来使用，内置函数则可以直接调用。**下面三种导入方式都以标准库模块 `math` 中的平方根函数 `sqrt()` 为例。

### 9.1 导入模块

```python
import math
print(math.sqrt(16))  # 4.0
```

`import math` 让名称 `math` 引用这个模块对象。调用时用点号访问模块中的函数，因此写成 `math.sqrt(16)`，返回值为4.0，再由 `print()` 输出。保留模块名前缀，能够直接看出函数属于哪个模块。

### 9.2 直接导入名称

```python
from math import sqrt
print(sqrt(16))  # 4.0
```

`from math import sqrt` 直接引入 `sqrt`，所以调用时写 `sqrt(16)`。当前程序能使用哪些名称，要看实际执行的导入语句。仅执行这一条语句时，得到的是 `sqrt` 名称，模块名 `math` 尚未因此绑定。

直接导入名称后还应避免同名覆盖。`from math import *` 会引入多个名称，初学时不易判断每个名称所属的模块。明确写出要导入的名称，可以让调用关系和命名冲突更容易检查。

### 9.3 使用别名

```python
import math as m
print(m.sqrt(16))  # 4.0
```

`as m` 让名称 `m` 引用导入的模块对象，因此后续调用写成 `m.sqrt(16)`。别名应在这一段代码中保持一致，否则可能引用到尚未定义的名称。

| 导入写法 | 对应调用 |
| --- | --- |
| `import math` | `math.sqrt(16)` |
| `from math import sqrt` | `sqrt(16)` |
| `import math as m` | `m.sqrt(16)` |

安装与导入分别发生在环境准备和程序执行两个层面。安装让相关包在所用Python环境中可用，导入让当前程序能够访问它提供的名称。`math` 已随标准库提供，通常无需另行安装。第三方库安装完成后，代码中通常仍需写出相应导入语句。

## 参考答案与解析

**第1题 A**

`temp_2` 以字母开头，后面由字母、下划线和数字组成，符合命名规则。`2temp` 以数字开头，`if` 是保留字，`temp-value` 会被按减法表达式理解。

**第2题 C**

Python名称区分大小写，因此 `temp` 与 `Temp` 可以同时表示两个不同的绑定。名称可以使用符合规则的中文字符，也可以使用英文等字符，合法性仍取决于标识符规则。

**第3题 B**

执行第二行时 `c` 为0，右侧求得32.0并赋给 `f`。第三行只把 `c` 改为100，未重新计算 `f`，所以最终输出32.0。

**第4题 D**

给内置名称赋值会改变它在当前代码中的绑定，后续调用可能因此失败。`if` 等保留字具有语法用途，直接用作普通变量名会产生语法错误。

**第5题 C**

引号表明两个操作数都是字符串，因此 `+` 将文本连接成 `"123"`。`print()` 显示字符串内容，输出123。

**第6题 A**

终点-1指向末尾字符F，切片排除这个终点，所以 `text[:-1]` 取得前面的 `"82"`。只写 `text[-1]` 则取得单位 `"F"`。

**第7题 D**

前三个字符的索引是0、1、2，第一个数字1的索引为3。`text[3:]` 从这里一直取到末尾，得到 `"100"`，而 `text[:3]` 取得币种前缀。

**第8题 B**

控制台输入12时，`input()` 返回字符串 `"12"`。如果需要把它用于数值计算，再根据题意执行 `int()` 或 `float()` 转换。

**第9题 D**

`float("12.5")` 返回浮点数12.5。`int("12.5")` 无法直接解析带小数部分的文本，`print()` 的作用是输出，传给 `input()` 的实参 `"12.5"` 则只作为提示文本。

**第10题 B**

`eval()` 把文本解释为Python表达式，因此可以处理加法，也可以执行函数调用表达式。读取普通数值时，调用 `int` 或 `float` 等内置类型进行转换，即可按数值格式处理输入。

**第11题 A**

`number` 为2，第一个条件成立，输出A后跳过同组的 `elif` 和 `else`。第二个条件虽然也可能成立，这次执行并不会再判断它。

**第12题 C**

Python通过缩进确定语句所属的代码块。每层4个空格是常用风格，语法还要求缩进层次正确，同一代码块保持一致。

**第13题 B**

三引号可以界定多行字符串。位于模块、函数或类主体开头时，字符串可以承担文档说明作用。普通注释使用 `#`，两者应按各自语法理解。

**第14题 D**

第一次调用输出A，并把末尾内容设为空字符串，所以光标仍停在同一行。第二次接着输出B，再追加默认换行，最终只有一行 `AB`。

**第15题 C**

格式说明 `.2f` 要求按定点形式显示两位小数。32.0的小数部分补足为两位，因此显示32.00。

**第16题 A**

先从82中减去偏移32，再除以变化比例1.8，得到约27.7778摄氏度。保留两位小数并加上目标单位，结果为 `27.78C`。

**第17题 A**

索引-1表示末尾字符，前提是字符串中至少存在一个字符。空字符串没有可访问的位置，使用 `[-1]` 会产生索引错误。

**第18题 C**

`from math import sqrt` 直接引入 `sqrt`，所以相应调用为 `sqrt(16)`。只有另外执行了 `import math` 等语句，让模块名也可用时，才可以通过 `math.sqrt()` 访问。

**第19题 D**

`as m` 将导入模块绑定到名称 `m`，因此通过 `m.sqrt(16)` 调用 `math` 模块中的平方根函数，返回值为4.0。

**第20题 B**

提交程序应按输入计算结果，再严格生成规定的输出。题目没有要求的提示、错误的换行或小数位，以及用固定文本代替实际计算，都可能导致评测不通过。
